# LapSimLab 圈速模擬

獨立的繁體中文桌面工具，沿用 `new/lapsim` 的準穩態速度規劃模型。可將整個 `LapSimLab` 資料夾複製到其他位置使用。

## 啟動與操作

雙擊 `Start-LapSimLab.bat`，或在此資料夾執行 `python run.py`。需要 Python 3.10 以上、Tkinter 和 NumPy。若使用的 Python 尚未安裝 NumPy，可執行 `python -m pip install -r requirements.txt`。

1. 在左側調整模擬、車輛與懸吊、傳動與煞車設定。比值欄位以 0–1 表示比例，速度上限以 m/s 輸入。
2. 按「計算」或 **F5**。右側會顯示預估圈速、取樣路徑長度、最高車速與最大橫向加速度。
3. 切換結果分頁查看賽道速度圖、速度曲線、縱橫向加速度、四輪輪荷、側傾／俯仰及空力。按「匯出完整 CSV」可儲存本次計算的所有逐點訊號。

## 逐點訊號檢視

完成圈速計算後，切到右側「訊號檢視」。可用中文名稱、欄位名或單位搜尋，再以時間或距離為橫軸繪圖。按住 Ctrl 或 Shift 可比較最多四個同單位訊號。拖曳取樣滑桿或點圖可讀出該點的數值。

完整 CSV 保留原本的摘要欄位，另附四輪簧上／簧下位移、速度、加速度、輪胎三向力、轉向角、Camber、受載半徑、輪速、馬達轉速、扭矩與踏板命令等訊號。每一列對應圈速模型的一個取樣點，輪序為 FL、FR、RL、RR。

簧上位移 `zs` 與簧下位移 `zu` 以靜態為基準且向上為正，原有 `heave_mm` 以向下為正。`zs` 由 Heave 和合成 Roll／Pitch 換算至車身四角。`zu` 取當前受載半徑減去靜止受載半徑。各角速度與加速度由逐點位移做時間差分。逐輪縱向力、扭矩與踏板命令是按速度規劃與傳動／煞車比例得到的準穩態估算。

四輪相對位移欄位 `zs_minus_zu_*_mm` 為同一輪的 `zs − zu`。相對於靜止狀態，正值表示車身角點與輪心的垂直距離增加，負值表示距離縮短。完整 CSV 也逐點記錄合成側傾 `roll_deg`、合成俯仰 `pitch_deg`，以及由賽道路徑切線估算的航向角 `yaw_deg`。

## 分析分頁

右側的分析分頁可獨立於圈速計算使用。初次開啟會繪製預設曲線，調整條件後按「更新曲線」。

- **空力掃描**固定車速、Heave 及另一個姿態角，掃描 Roll 或 Pitch。可查看下壓力與阻力、前後軸下壓力或 CL/CD。
- **馬達曲線**顯示左側選用的 CSV 單馬達轉速／扭矩資料。圖的範圍以 CSV 內的轉速為準。
- **輪胎力掃描**沿用圈速的輪荷與輪胎模型。可切換四輪合計或單輪。側向曲線為 Fx = 0 時的 Fy 峰值，縱向曲線則是在指定橫向加速度下剩餘的驅動／煞車抓地。指定的橫向力按輪荷比例分配，任一輪無法滿足時，該點合計 Fx 顯示為 0。縱向曲線表示輪胎能力，未套用馬達、煞車或空阻限制。

掃描時 Roll 直接用來換算 camber。Pitch 透過空力影響輪荷。固定的縱、橫向加速度決定載重轉移。輪荷沿用圈速模型，總下壓力按靜態前後配重分配。

## 內附輸入資料

下列檔案都位於 `input_data/`。在「模擬與資料」可選擇同格式檔案，或按「恢復預設」重新載入內附檔案的路徑。

| 檔案 | 格式 |
| --- | --- |
| `fsae_A_2025.csv` | 原 LapSim 的 LINE／ARC 賽道分段。長度、半徑與平面座標用 m，角度用 deg。 |
| `hoosier_43075_r20_w8.json` | Hoosier R20 W8 的簡化 Fx／Fy 輪胎模型。 |
| `motor_speed_vs_torque.csv` | 與 VehicleLab 同一份單馬達曲線，`speed` 為 RPM，`torque` 為 N·m。 |
| `modal_aero.json` | 隨 Heave、Pitch 和 Roll 變化的空力係數。 |

## 計算範圍

LapSim 以分段中心線的取樣點估算側向抓地上限，再以前後向掃描納入驅動與煞車能力。計時使用取樣點間的平面距離，因此顯示的路徑長度會與 CSV 分段長度加總略有差異。輪胎力查詢沿用原模型的荷重與外傾角擬合範圍。取樣點上限為 25,000，超過時可增大取樣間距。

### 車身側傾與俯仰

在「車輛與懸吊」輸入前軸 Roll 剛性（每輪，N/m）、前軸 Heave 剛性（整軸，N/m）與共用的後／前剛性比。後軸 Roll 和 Heave 各自用前軸的數值乘上這個比值。預設 `1.0` 表示前後相同，`1.2` 表示後軸為前軸的 120%。

每輪垂直壓縮量取 `δ = max(Fz, 0) / K_tire`。前後軸各自以 `atan2(δ右 − δ左, 輪距)` 算出輪胎側傾，再取兩軸平均並加到懸吊側傾，得到整車 roll。Pitch 則用前後軸平均壓縮差相對於靜止狀態的變化，除以軸距取反正切後加到懸吊俯仰。合成姿態用於空力計算與「車身姿態」圖，camber 依合成 roll 換算。
