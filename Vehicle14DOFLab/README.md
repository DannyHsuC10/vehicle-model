# LP03 14 DOF 圈速模擬

網頁版的本機預覽及 GitHub Pages 設定請見 [網頁版說明](../web/README.md)。

## 桌面工作台

在 Windows 雙擊 [Start-14DOF-GUI.bat](Start-14DOF-GUI.bat)，或在本專案資料夾執行 `py -3 -B run.py --gui`。可將整個資料夾搬到其他位置或重新命名。所需的預設輸入及求解模組分別位於 `input_data/` 和 `_vendor/`。

`_vendor/` 內含本模型使用的 LapSimLab、Pacejka 與 SuspensionDynamicsLab 程式副本。其他工具更新後，若要將同一改動套到 14DOF，需同步更新對應副本。

- 在「工況」選擇封閉賽道、9.125 m 定圓或直線加速。圈速預設使用 100 km/h 及 2.0 g。
- 在「車身」、「動力／空力」、「四輪」及「懸吊」編輯質量與重心、輪端參數、傳動、空力、彈簧、阻尼及運動比。每次執行會把使用的車輛及懸吊設定另存到該筆結果的 `inputs` 資料夾。「另存設定」可建立下次要載入的設定。
- 「懸吊」分成彈簧、阻尼、運動比與限位。壓縮／回彈各兩段使用六格輸入。彈簧的分段剛性與力曲線、阻尼的分段係數與力曲線都各自共用「CSV 查表」，可直接匯入或儲存範本。
- 在「煞車」設定液壓煞車。在「四輪」按「選擇 TIR…」可換用四輪共用的輪胎模型，LP03 預設為 `Hoosier_43075_R20_W8_candidate.tir`。同頁可設定輪胎自由半徑，結果區可查看逐輪滾動半徑。
- 在「動力／空力 → 動力」按「匯入 CSV…」可更換四顆馬達共用的馬達曲線。多電壓包絡使用 `vdc_V,rpm,T_shaft_Nm`，單條曲線使用 `rpm,T_shaft_Nm` 或 `speed,torque`。轉速單位是 RPM，扭矩填減速前的馬達軸端 N·m。轉速取線性內插，超出曲線的最高轉速時軸端驅動扭矩為零。只有多電壓包絡會依匯流排電壓查表。LP03 預設使用 [lp03_voltage_envelope.csv](input_data/lp03_voltage_envelope.csv)。
- 在「懸吊幾何」可設定固定值或匯入 Roll Center、Anti、Camber 與 Bump Steer 曲線／曲面。「啟用 Roll Center 與 Anti 傳力」控制這兩項幾何反力。結果提供外傾角、Bump Steer、幾何傳力及 SAE 滾阻力矩的逐輪圖表。
- 按「執行模擬」查看進度及執行紀錄。每次執行會在 `results/lap/`、`results/skidpad/` 或 `results/straight/` 建立資料夾，存放計時、遙測與 SVG。工作台會將該次使用的輪胎、馬達、懸吊及賽道資料一併留在 `inputs/`。
- 「分析結果」可切換已保存的工況，或開啟既有遙測 CSV。可查看速度地圖、車速、加速度、四輪輪荷、滑移、懸吊行程、輪端扭矩、空力及空力作用點。滑鼠移到時間圖會顯示對應的數值。
- 在「駕駛動畫」選擇跟車或俯視視角，按「播放」或拖曳時間軸。路面顯示左右邊界及中央虛線。動畫會自動讀取 `car_stl` 下的車身與四輪 STL，建立供回放用的簡化網格，並以 CAD 輪心和地面對齊模型。車身姿態、輪跳、轉向和輪胎旋轉由遙測驅動。油門與煞車條顯示駕駛指令百分比，右側同步顯示當下的縱向／側向加速度（g）和四輪輪荷（N）。可切換 0.25× 至 4× 播放速度。

STL 分件以 `body.stl`、`wheel_FL.stl`、`wheel_FR.stl`、`wheel_RL.stl`、`wheel_RR.stl` 結尾，可以共用匯出檔名前綴。五個檔案須使用同一座標原點，單位為 mm，X 向前、Y 向左、Z 向上。工作台保留 CAD 尺寸和原始檔，回放時簡化車身網格。已有遙測可直接用 STL 車輛播放，若缺少分件則使用示意車。

## 命令列

在 Windows 可雙擊 `Start-14DOF-Lap.bat`，以 LP03 參數從靜止出發完成 FSAE A 2025 賽道。需要 Python 3.10 以上及 NumPy。桌面工作台另需 Tkinter。第一次安裝依賴可在本專案資料夾執行以下指令。

```powershell
py -3 -m pip install -r requirements.txt
```

## 執行圈速模擬

```powershell
# 預設 FSAE A 2025
py -3 -B run.py

# 半徑 9.125 m 定圓。重現先前 5.5 m/s² 的定圓基準
py -3 -B run.py --track examples/skidpad.csv --initial-speed 7 --warmup-laps 1 --lateral-limit 5.5

# 75 m 直線。從靜止全油門加速至終點
py -3 -B run.py --straight 75

# 用較小步長檢查圈速和訊號變化
py -3 -B run.py --step 0.0025
```

預設賽道使用隨專案附上的 [FSAE A 2025](input_data/fsae_A_2025.csv)。用 `--track` 可選擇其他 LapSimLab 格式的封閉 LINE／ARC CSV，`--width` 設定以中心線為基準的總寬度，預設 3 m。可用 `--laps`、`--warmup-laps`、`--initial-speed`、`--max-speed` 與 `--lateral-limit` 設定工況。速度使用 m/s，側向加速度使用 m/s²。其餘選項可用 `--help` 查看。

圈速駕駛的預設最高目標車速為 100 km/h（約 27.778 m/s），彎道側向加速度目標為 2.0 g（19.620 m/s²）。

計算時終端機約每 2 秒顯示目前的暖胎圈或計時圈、該圈完成百分比、沿中心線的進度距離及累計模擬時間。每次通過起終點線會立即顯示該圈完成。

## 結果檔案

完成後會輸出兩份 CSV 與五張可用瀏覽器開啟的 SVG，並在終端機顯示完整路徑。命令列的預設結果也依工況分類，指定 `--output` 時則使用你提供的路徑。摘要內的資料來源使用相對於摘要檔的路徑。若命令列引用專案外的自訂資料，搬移前也需保留那些來源檔案。

- `telemetry_summary.csv` 每個計時圈一列，含圈速、開始和通過終點的時間、賽道長度，以及使用的賽道與設定檔。第一個計時圈會從最後一個暖胎圈過線時開始。
- `telemetry.csv` 包含暖胎圈與計時圈的逐點車身及四輪遙測。
- `*_speed_map.svg` 以顏色表示實際行駛軌跡的車速，並疊加賽道中心線。定圓圖顯示計時圈。
- `*_speed_time.svg`、`*_acceleration_time.svg`、`*_aero_time.svg`、`*_aero_cop_time.svg` 分別顯示車速、縱向／側向加速度、下壓力／阻力及三軸空力作用點。若有暖胎圈，時間圖會標記計時開始位置。

`--output skidpad.csv` 會把逐點資料寫到 `skidpad.csv`、圈速摘要寫到 `skidpad_summary.csv`，圖檔同樣以 `skidpad_` 開頭。可用 `--summary` 自訂摘要的檔名。直線摘要記錄距離、通過終點的耗時與終速。

虛擬駕駛在每 0.02 秒依實際車輛位置與速度更新轉向、油門和煞車。目標速度由賽道曲率、車速上限以及加速與煞車能力的規劃值生成。模型以時間域 RK4 積分，預設最大步長 0.005 秒。車速低於 6 m/s 時，步長上限縮至 0.0025 秒以解析起步輪速。圈速由車輛重心實際通過起終點線的時間計算。每列 CSV 記錄位置、車速、車身姿態、駕駛輸入、中心線偏差及四輪的輪速、懸吊行程、輪荷、滑移率、側滑角、輪胎力與驅動／煞車扭矩。超出重心可行走廊或超時會回報失敗。

## 模型與參數

啟動時會顯示以下兩份實際載入的設定檔。

| 設定檔 | 可調參數 |
| --- | --- |
| [Vehicle14DOFLab/lp03.json](lp03.json) | 偏航及輪系慣量、輪胎自由半徑、胎壓、靜態外傾、傳動、液壓煞車與姿態空力。也可更換懸吊專案、輪胎 TIR 及馬達資料。用 `--config` 可選擇另一份車輛設定。 |
| [input_data/LP03.json](input_data/LP03.json) | `vehicle` 設定質量、重心、軸距、輪距與側傾／俯仰慣量。`tires` 設定簧下質量及垂向剛性與阻尼。`channels` 設定懸吊彈簧、阻尼及運動比。這份專案路徑由車輛設定的 `suspension_project` 指定。 |

| 自由度 | 方程與資料 |
| --- | --- |
| 車身 6 DOF | 縱移、橫移、升沉、側傾、俯仰、偏航。逐輪接地力驅動整車平面運動，縱向與側向力透過力臂作用於俯仰與側傾。空力依姿態更新，並依作用點相對重心的位置施加力矩。 |
| 四輪輪跳 4 DOF | 四個簧下質量各自垂向運動。沿用 SuspensionDynamicsLab 的 LP03 模態懸吊、運動比、彈簧、壓縮／回彈阻尼、限位，以及輪胎垂向剛性與阻尼。輪胎離地時接地力歸零。 |
| 四輪自轉 4 DOF | 逐輪積分自轉角及角速度。LP03 馬達電壓包絡經傳動比轉成輪端扭矩，並計入煞車、滾阻及接地反扭矩。 |

輪胎切向力使用 Hoosier 候選 TIR 的 Magic Formula 6.1.2 組合滑移，包含縱向力 Fx、側向力 Fy 與自回正力矩 Mz。低速以連續的飽和力模型銜接，煞車在近鎖輪區採正則化力矩。Ackermann 依軸距、輪距和虛擬駕駛的轉向指令計算兩前輪舵角。

`lp03.json` 設定資料來源、胎壓、靜態外傾、輪系慣量與傳動。LP03 等效懸吊資料採 320 kg 整車質量、每輪 13 kg 簧下質量。偏航慣量沿用 LapSim 的 130 kg·m²，每輪 0.9 kg·m² 的自轉慣量及零靜態外傾是可編輯的初始假設。車架採剛性與小側傾／俯仰角近似，懸吊使用等效輪端模型。CLI 使用平坦路面。Python 的 `simulate_laps(..., road=...)` 可餵入依模擬時間變化的四輪路面高度與垂直速度，依序為 FL、FR、RL、RR，單位為 m 與 m/s。

### 懸吊幾何

- Roll Center 可採前後軸固定離地高度或 CSV 查表。啟用後，前後軸各自依該步的側向輪胎合力、輪距與 Roll Center 高度分配左右幾何反力。
- Anti 採全車載重轉移百分比，沿用懸吊專案內已包含前後軸力分配的比例定義。求解依縱向輪胎合力的方向，在煞車的前 Anti-dive／後 Anti-lift 與加速的前 Anti-lift／後 Anti-squat 間切換。幾何反力在簧上與簧下質量間成對作用，改變由連桿與彈簧各自承擔的傳力。
- Camber 獨立於幾何傳力開關，可用每 25 mm 壓縮的線性 Gain 或 CSV 查表。輪頂外傾為正，以無空力靜態平衡的懸吊行程為基準。輪胎模型合成靜態外傾、查表或線性外傾變化及車身側傾投影，再依輪胎 TIR 的外傾範圍限幅。
- Bump Steer 表給四輪的舵角修正量，左轉為正。模型將修正加到前輪 Ackermann／後輪名義舵角後，據此計算輪胎側滑角與車身受力。Camber 和 Bump Steer 皆使用修正前的舵角查表，避免舵角修正同時成為自己的輸入。
- 預設 LP03 的幾何傳力開關為關閉、四輪 Camber Gain 為零。Roll Center 和 Anti 的數值儲存在懸吊專案的 `vehicle` 區塊，開關和 Camber Gain 儲存在車輛主設定的 `suspension_geometry`。逐輪遙測中的 `roll_center_force_n` 與 `anti_force_n` 以向上作用於輪端為正。

在「懸吊幾何 → 曲線／曲面 CSV…」選擇幾何項目，可儲存有正確欄名的範本或匯入 CSV。Roll Center 與 Anti 的單軸欄名相容 SuspensionDynamicsLab 的查表 CSV。

| 項目 | 可用查表軸 | 輸出 |
| --- | --- | --- |
| Roll Center | 軸平均輪跳、前軸輪跳 × 後軸輪跳、軸平均輪跳 × 車身側傾、軸平均輪跳 × 前軸等效舵角，或單獨前軸等效舵角 | 前／後 Roll Center 高度或高度變化 (mm) |
| Anti | 同上 | 四種 Anti 的絕對比例 (%) 或相對變化（百分點） |
| Camber | 各輪輪跳、各輪名義舵角，或各輪輪跳 × 各輪名義舵角／前軸等效舵角 | 四輪相對靜態外傾的變化量 (°) |
| Bump Steer | 同 Camber | 四輪相對名義舵角的修正量 (°) |

輪跳欄位採 mm，壓縮為正，伸長／抬升車身所對應的懸吊回彈為負。車身左側抬高、舵角向左為正。單軸表採線性插值，雙軸表採雙線性插值並要求完整矩形網格。查表超出範圍時取邊界值。Roll Center／Anti 的相對變化量加到頁面設定的基準值。絕對值表及 Camber 角度表會停用該項目的固定值／線性 Gain 欄位。表格資料會嵌入車輛設定及每次執行的快照。

### SAE 滾動阻力

14 DOF 使用輪胎模組的 `RRT_SAE` 近似式，以各輪當下輪荷、胎壓、沿輪胎方向的縱向速度，以及車輛設定的輪胎自由半徑計算滾阻力矩。力矩逆著輪軸轉動方向，且接近停止時平滑降至零。逐輪的 `rolling_resistance_nm` 採有號力矩，正常向前轉動時為負。

### 彈簧、阻尼與觸底

彈簧的「觸底行程」從無空力的靜態平衡位置起算，使用的是軸心壓縮量。觸底時力與原彈簧曲線接續，之後以「觸底後總剛性」延伸。剛性填 0 可停用觸底。伸長限位與安裝預壓在「運動比與限位」。

CSV 第一列決定查表類型。資料的行程或速度須嚴格遞增，可在介面的查表模式儲存下列範本。

| 資料 | CSV 欄名 |
| --- | --- |
| 分段彈簧剛性 | `travel_mm,stiffness_n_per_mm` |
| 彈簧力曲線 | `travel_mm,force_n` |
| 分段阻尼係數 | `speed_mps,compression_ns_per_m,rebound_ns_per_m` |
| 阻尼力曲線 | `speed_mps,compression_n,rebound_n` |
| 運動比行程曲線 | `travel_mm,mr` |

分段表的每列表示新一段開始的位置或速度。阻尼表使用速度大小並從 0 m/s 開始，力曲線的壓縮與回彈也從 0 N 開始。舊專案已有的曲線資料會載入為同一個查表模式。

運動比須為正且無單位。行程點之間使用線性內插，超出表格範圍時使用端點的運動比。單一固定運動比可用「固定值」輸入。

### 自由半徑與液壓煞車

滾動半徑使用受載半徑近似。每輪即時更新為「自由半徑 − 輪荷 ÷ 輪胎垂向剛性」，並限制在 0 至自由半徑內。它會進入滑移率、輪胎縱向反扭矩及行進起步的輪速初始化。舊設定的 `rolling_radius_m` 會作為自由半徑讀入。

LP03 使用 LapSimLab 液壓煞車。可調最大踏板力、踏板比、平衡桿前軸分配、前後總泵與卡鉗的活塞直徑、各輪卡鉗活塞數、前後碟盤有效摩擦直徑，以及來令片摩擦係數。舊設定檔載入時採液壓模型，缺少的液壓欄位使用 LapSimLab 的示例值。

目前圈速對應沿賽道中心線行駛與保守的駕駛速度設定。圈速會隨駕駛、車輛與賽道設定改變，LP03 實車預測仍需以實測參數和遙測校驗。

## 姿態空力

在「動力／空力 → 空力」可編輯基準係數、姿態敏感度及作用點，或直接匯入 LapSimLab 的空力 JSON。LP03 預設使用 `aero.model = "modal"`。LapSimLab 模態公式以無空力靜態平衡為基準，用升沉（m）、俯仰及側傾（rad）更新 CL、CD 與空力平衡。力隨動壓變化，阻力沿平面速度的反向施加。行進起步以當下姿態的空力求初始懸吊平衡。

前軸下壓比例與俯仰決定作用點前後位置，側傾敏感度決定左右位置。模擬將下壓力和阻力對整車重心產生的側傾、俯仰和偏航力矩加入方程。遙測提供 `cop_x_m`（向前為正）、`cop_y_m`（向左為正）、`cop_z_m`（離地高度）、`CL`、`CD` 及三軸空力力矩。

LP03 以 [LapSimLab 的示例係數](input_data/modal_aero.json) 為基礎，並在 [lp03.json](lp03.json) 採用暫定的 `Krr = 100`、`Kd_h = 0.8`、`Kd_p = 0.3`、`Kd_r = 0.3`。原範例的 `Krr = 1000` 在 LP03 的 9.125 m 定圓造成解發散。三項非零 `Kd` 讓阻力隨姿態變化。匯入 LapSimLab JSON 會套用該檔的係數。舊版固定係數設定仍可直接開啟，也可在介面切換為「固定係數 v²」。
