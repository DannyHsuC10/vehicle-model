# SuspensionGeometryLab 懸吊幾何工作台

本工具是獨立的五頁 Tkinter 桌面介面。Canvas 圖表、平移縮放、捲動元件與 CSV 匯出均包含在本資料夾內，可單獨複製整個 `SuspensionGeometryLab` 資料夾使用。完整靜態構造直接呼叫套件內的 `static/fv/wireframe_geometry.py`，與套件內的 `static/fv/tk_wireframe.py` 使用相同來源。FV、SV 的運動零位均來自這份靜態結果；WE3D 使用其中合併 FV / SV 的真實 3D 主銷。

幾何程式已收進 `suspension_geometry_lab/static/`，輪端旋轉函式位於 `suspension_geometry_lab/wheel_end_geometry.py`；全部使用套件內 import，不依賴 `VehicleLab`、`vehicle_lab` 或 `new` 資料夾。圖表基底位於 `suspension_geometry_lab/chart_base.py`，捲動元件位於 `suspension_geometry_lab/widgets.py`。

## 啟動與參數操作

在本資料夾雙擊 `Start-SuspensionGeometryLab.bat`，或先切換到 `SuspensionGeometryLab` 資料夾再執行：

```powershell
python -m suspension_geometry_lab
python -m suspension_geometry_lab --project projects/my_suspension.json
```

也可執行 `python run.py`。專案 JSON 可儲存在本工具自己的 `projects/`。

獨立靜態線框預覽可雙擊 `Start-StaticWireframe.bat`，或執行 `python -m suspension_geometry_lab.static.fv.tk_wireframe`；同樣使用套件內幾何程式。

需要 Python 3.10+、Tkinter 與 NumPy；PNG 匯出需要 Pillow。這台電腦的 Codex Python 已具備套件。其他環境可安裝：

```powershell
python -m pip install -r requirements-suspension.txt
```

1. 按右上「共用車輛／懸吊設定」，可編輯車輛 / 輪胎、24 個硬點、前後軸參數與掃描範圍，並選擇懸吊參數模式或硬點模式，再按「套用全部設定」。
2. 參數模式下，各分析頁左側也可編輯相關設計；硬點模式下，懸吊欄位顯示唯讀反算值，共用車輛與掃描設定仍可編輯。按「套用左側參數並重新解算」後，五頁會同步使用新設定，舊結果與掃描快取會清除。未套用的輸入框內容尚不屬於專案。
3. 按「儲存專案」或 Ctrl+S 儲存 JSON。按「另存專案」可保留不同設計版本，按「匯入」或 Ctrl+O 可載入專案。檔名旁的 `*` 表示已套用設定尚未儲存。
4. 選擇圖表，拖動滑桿觀察目前姿態。拖曳過程會持續求解、顯示已完成的姿態，再接續求解最新滑桿位置，不必放開滑鼠。曲面與範圍圖是整個設定範圍的掃描，不會隨目前姿態改變掃描邊界。
5. 3D 圖拖曳旋轉，2D 圖拖曳平移；滾輪縮放。幾何圖與 RC / PC 位置分布圖的 X、Y 軸維持相同單位的等比例，視窗縮放後也會維持。滑桿更新時保留目前縮放、平移與視角；按「重設視角」或雙擊才會重新置中。切換圖表、座標模式、車軸或套用新設計時會重新配合圖形範圍。結果表可捲動查看所有數值。

未指定 `--project` 啟動時，基準專案為 `suspension_geometry_lab/default_project.json`；指定時則載入該專案。預設前後驅動力比例為 **50%：50%**（`drive_force_front=0.5`，後軸自動為 `1−0.5`）。其餘基準幾何沿用 `static/car.py` 的原始設定，包括前後 FVSA 1 m、RC 35 / 40 mm、KPI 12 / 13 deg、caster 5 / 0 deg。工具的可編輯設計值只讀 JSON；套件內的 Car / Suspension 類別只用作靜態求解器的型別介面，不會呼叫它們的預設值建構子。獨立靜態線框預覽仍可使用原有設定。

本工具與原 Vehicle Lab 的 JSON 結構不同；兩者用途、硬點來源與參數種類不同，開啟錯誤格式會明確顯示錯誤。

## 輸入上下界與關聯檢查

共用設定與五頁左側的一般設計參數、掃描設定輸入框下方顯示允許範圍；硬點 XYZ 與 A 臂車身 X 不設人工數值上下界。輸入途中可暫時留白或輸入負號，無效數值會以橘色標示；按套用時必須修正，無效草稿不會覆蓋已套用的設計。讀取與儲存 JSON 也使用相同的數值驗證，不會自動截斷輸入值。專案名稱允許 1～128 字元，不可全為空白。

以下為本工作台的設計輸入保護範圍，並非賽例規範或可製造性認證；各欄單獨合格後，仍須通過關聯與幾何求解檢查。除特別註明外，包含上下界。

| 車輛／輪胎欄位 | 允許範圍 |
|---|---|
| 軸距 | 0.5～5 m |
| 重心至前軸 | 大於 0、至多 5 m，且小於軸距 |
| 前／後輪距 | 各 0.4～3 m |
| 重心高度 | 0.05～1.5 m |
| 總質量 | 50～2000 kg |
| 重力加速度 | 9～10 m/s² |
| 車底離地高 | 0～0.5 m，且不高於重心 |
| 輪胎自由半徑 | 0.1～0.6 m |
| 輪胎垂直剛性 | 10000～1000000 N/m |
| 胎寬 | 0.05～0.6 m |
| 輪圈內徑 | 0.1～1 m，且小於輪胎自由直徑 |
| 輪圈避讓間隙 | 0～0.1 m，且兩倍間隙小於輪圈內徑 |
| 靜態避讓轉角 | 0～80 deg |
| 前煞車比例 | 大於 0、小於 1 |
| 前軸加速驅動力比例 | 0～1；後軸自動為 1−前軸比例 |

| 前／後軸欄位 | 允許範圍 |
|---|---|
| FVSA | 0.05～20 m |
| Roll center 高度 | −0.5～1 m |
| KPI、Caster | 各 −45～45 deg |
| Scrub radius、Mechanical trail | 各 −0.3～0.3 m |
| Au／Al 輪心上／下偏距 | 各 0.005～0.5 m |
| 上／下 A 臂車身 \|Y\| | 各 0～1.5 m，且小於該軸半輪距 |
| 煞車與加速 Anti 目標 | 各 −2～3（−200%～300%），保留負值與超過 100% 的設計 |
| 可編輯的有號 SVSA | −100～−0.05 m 或 0.05～100 m |

有驅動力車軸的 SVSA 為唯讀求解結果；無驅動力車軸的加速 Anti 為唯讀 0。這些非輸入結果不套用上述設計輸入上下界，避免把接近平行力線所產生的大 SVSA 誤判為輸入錯誤。

| 掃描欄位 | 允許範圍 |
|---|---|
| 上壓／下垂行程 | 各 0～200 mm，不可同時為 0 |
| 轉向範圍 ± | 大於 0、至多 80 deg |
| Caster 掃描下／上限 | 各 −45～45 deg，且下限小於上限 |
| 每軸網格點數 | 5～51 的整數 |

另檢查前後軸的輪胎負載半徑均大於 0。接點重合、A 臂共線、上下球接點順序、平行 Anti 力線等無效幾何，仍由求解器拒絕。設定範圍中的部分掃描姿態可能不可達，會依原有方式標為無解。

硬點 XYZ 不設固定或依車輛尺寸推算的人工數值上下界，也不限制 Z 必須非負。仍須輸入三個有限座標，保留左右側別、鏡射對稱與既有 A 臂幾何檢查。預設使用參數模式，24 個硬點由幾何產生實際座標；直接編輯 XYZ 時仍使用實際數值，不將 XYZ 設為 `null`。

A 臂車身 X 不設固定數值上下界；八格預設皆為空白／`null`，自動採用輪圈避讓幾何算出的極限接點。手動指定 X 時仍須符合該支 A 臂的實際幾何條件，見下一節。

新編輯的設計欄位在套用時取到最接近的級距，正好在兩格中間時取離零較遠的一格。

| 設計欄位 | 級距 |
|---|---|
| 前／後輪距、FVSA、RC 高度、上下 A 臂車身 \|Y\| | 0.005 m |
| KPI、Caster | 0.5° |
| Scrub radius、Mechanical trail | 0.001 m |
| 所有 Anti 目標 | 5 個百分點（JSON 比例 0.05） |

舊專案及未編輯欄位保留原值。Anti 反算、姿態、曲面、CSV 與報告的結果以 5 個百分點呈現，幾何求解使用原始計算精度。

## A 臂車身接點的八個 X 設定

共用設定的「前軸參數模式」與「後軸參數模式」頁籤各新增四個欄位：上 A 臂前／後接點 X、下 A 臂前／後接點 X，共八個參數。輸入單位為 **mm**；使用全車座標，X 向前、前軸 X=0、後軸 X=−軸距，並非相對各輪心的距離。每組數值同時用於左右兩側。

欄位留白時使用原本輪圈避讓幾何求出的極限接點，保留舊專案的行為。原來標為「FV 上／下接點 X」的欄位，現改標為「上／下 A 臂車身 |Y|」，仍以 m 輸入，避免與新增的全車縱向 X 混淆。

接點計算先保留 A 臂參考平面與指定的車身 Y，將輸入 X 代入平面方程解 Z。若平面法向量為 n、平面上一點為 P₀：

```text
Z = P₀z − [nx·(X−P₀x) + ny·(Y−P₀y)] / nz
```

每次計算都重新以輪圈避讓幾何取得該支 A 臂的最前、最後接點，作為 X 的閉區間範圍。前後兩個 X 都必須在範圍內，且 `後接點 X < 前接點 X`；不可重合或前後顛倒。範圍內的邊界值允許使用。

同一支 A 臂只要任一接點超限、順序錯誤，或固定 X、Y 後無法唯一求 Z，**草稿預覽的兩個車身接點皆回到原本的極限解**；其他 A 臂仍使用各自有效的設定。輸入值保留，不會靜默改寫：欄位旁顯示目前允許範圍、實際採用的 X，超限處標註「超過極限範圍 xxx mm」；順序錯誤則顯示具體原因。桌面介面會拒絕套用或開啟含此類違規 X 的參數模式專案，必須修正輸入或留白，才可更新正式設計。

例如目前基準的右前上臂 X 極限約為 −274.529504～288.500086 mm。設定前 X=200、後 X=−200 mm 時，兩點的 Y 沿用 −255 mm，Z 由 A 臂平面求解；若前 X=400 mm，標註超出約 111.5 mm，前後兩點都使用原本極限解。

這八個欄位輸入後會自動更新範圍與超限標註；尚未編輯過硬點草稿時，也會同步更新表中的產生座標。按「由目前參數重新產生 24 點」可將目前有效設定或極限退回結果寫入硬點草稿，再切換至硬點模式。勾選直接編輯 XYZ 時，八個參數欄位停用，仍保留原本設定；此模式的 24 個原始 XYZ 不會被這八個參數覆蓋。

JSON 使用可選的 `arm_mount_x` 欄位，包含前後軸各四個 X，內部單位 m，`null` 表示自動使用極限；目前 `default_project.json` 明確將這八格全部設為 `null`。不含此欄位的舊專案同樣採用自動極限。核心腳本仍可讀寫舊的退回設定供檢查，桌面介面則執行上述套用檢查。HTML 報告另保存 `mount_position_checks`，記錄要求值、實際值、當時極限、超出距離與退回原因。

## 參數模式與 24 個懸吊硬點

預設維持懸吊參數模式。第一次開啟共用設定時，硬點表由目前參數解出的靜態場景產生；可按「由目前參數重新產生 24 點」更新草稿。若尚未手動編輯硬點，在同一視窗修改參數後勾選硬點模式，也會先使用最新參數產生座標。此按鈕會取代目前的硬點草稿，但不會在按「套用全部設定」前改動專案。

勾選「使用直接修改硬點 XYZ」後，在「24 個懸吊硬點」頁籤雙擊點名，輸入以逗號分隔的 X、Y、Z。表格與輸入框為 **mm**，JSON 與硬點 CSV 為 **m**。每輪六點，四輪共 24 點：

| 點名 | 定義 |
|---|---|
| UCA_F / UCA_R | 上 A 臂前／後車身接點 |
| UBJ | 上 A 臂外側球接點 |
| LCA_F / LCA_R | 下 A 臂前／後車身接點 |
| LBJ | 下 A 臂外側球接點 |

座標沿用 Vehicle Lab：X 向前、Y 向左、Z 向上；前軸 X=0、後軸 X=−軸距，地面 Z=0。修改 FL / FR 或 RL / RR 的任一點，對側同名點立即更新為 `(X, −Y, Z)`，不改動其他點。左右必須保持鏡射對稱；JSON 中的非對稱座標會明確拒絕。以 Y 值反號實作左右鏡射也可見 [MathWorks 的雙 A 臂硬點定義](https://www.mathworks.com/matlabcentral/mlc-downloads/downloads/33547d1c-88ab-48d1-9559-d39bc1c7a2db/1739468692/previews/Libraries/sm_car_doc/suspensions/html/sm_car_doc_susp_double_wishbone.html)。

右側顯示硬點反算的 KPI、caster、scrub radius、mechanical trail、FVSA、RC、SVSA、anti 與等效車身樞點等唯讀結果。硬點模式下，各分析頁的懸吊欄位同樣顯示反算值，不能直接編輯；共用車輛與掃描設定仍可編輯。原本的參數模式設計值保留，取消硬點模式後會恢復以該組參數求解；已編輯的硬點也會保存在專案中。未套用或取消視窗不會改變目前專案，無效幾何不會覆蓋已套用結果。

反算預覽自動更新：編輯硬點後立即重算；修改車輛／輪胎等欄位後，停止輸入約 0.2 秒便會刷新結果，無須手動按更新。這只更新草稿預覽，仍須按「套用全部設定」才更新正式分析。

硬點能反算靜態幾何，但目前的少量設計參數無法唯一重建全部 XYZ。尤其四個車身接點的縱向位置、旋轉軸傾角，不能只靠 FVSA、RC、KPI 等數值完整保留。因此硬點模式**以原始 24 點為幾何來源**，反算參數是結果，不會再用反算值重建並覆蓋座標。現有基準參數輸入的前 RC 為 35 mm；從產生的實際 3D A 臂旋轉軸反算，約為 34.76035 mm，兩者的差異會如實顯示。

硬點模式的分析方式：

- 靜態全車直接畫出原始 24 點及上下 A 臂；硬點 CSV 輸出相同的 24 個點名與座標。
- FV 在上、下球接點各自的 X 平面與對應 A 臂旋轉軸求交，作為等效 2D 樞點；以此反算零位 RC、FVSA 並沿用現有四連桿運動。這保留零位投影的瞬時運動方向，有限行程仍屬平面近似。
- SV 由每支 A 臂繞實際車身接點軸線的零位速度，取得 XZ 投影切線與側視瞬心，沿用固定切線與剛性羊角的運動近似。瞬心或中心位於無窮遠、沒有有限交點時，相關值顯示 N/A，不沿用舊數值。
- WE3D 使用輸入 UBJ–LBJ 定義的實際主銷軸，以原始輪心做 Rodrigues 轉向旋轉；caster 曲面與曲線使用這份硬點的設計 caster。

輪心仍由車輛軸距、輪距與負載輪胎半徑定位；六點不含輪心／輪胎姿態設定或轉向拉桿，未增加 bump steer 或行程與轉向耦合的完整空間求解。前後車身接點必須分離、A 臂三點不可共線、UBJ 必須高於 LBJ；目前 FV 等效樞點模型要求兩個車身接點有非零 X 間距。無法分析的草稿會顯示具體原因。

專案 JSON 支援可選的 `hardpoints: {enabled, corners}`，目前儲存格式為 `schema_version=4`，原有版本 1／2／3 專案可直接開啟。HTML 報告標示使用模式，輸入快照同時保存 24 點、保留的參數模式設計與目前 `static_parameters` 反算結果。所有程式仍位於 `suspension_geometry_lab`，不依賴 `new`。

## 五個頁面

| 頁面 | 滑桿 | 可切換圖表 |
|---|---|---|
| 前 FV | 左 / 右上壓行程，或 heave / roll | 動態機構、RC x′ / y′ 位置分布、RC 高度 y′ 曲面、RC 水平位置 x′ 曲面、左右 camber 與 camber gain 曲面 |
| 後 FV | 與前 FV 相同，使用獨立後軸設計 | 與前 FV 相同 |
| SV | 前 / 後上壓行程，或 heave / pitch | 動態機構、前後 caster、前煞車 Anti-dive、後煞車 Anti-lift、前加速 Anti-lift、後加速 Anti-squat、pitch center 高度 y′ / 位置 x′ 曲面、PC x′ / y′ 位置分布 |
| WE3D | steering，可選前 / 後軸 | 輪端 3D、steering × 設計 caster → 輪軸傾角曲面、接地半徑、接地 XYZ、3D 軌跡、caster / 傾角、三方向轉向力臂 |
| 靜態全車 | 旋轉與縮放 | 全車 3D / 前視 / 側視 / 上視，獨立開關前 FV、後 FV、SV 平面 |

### 曲面、曲線與分布圖的目前位置

切換到 FV／SV 的各個曲面、RC／PC 位置分布，或 WE 的 caster 曲面、轉向曲線與 3D 軌跡時，會標出目前滑桿姿態的位置。曲面與位置分布使用白框粉紅點；多條輪端曲線各有與該曲線同色的點。深色標籤框顯示當前座標、數值與單位，3D 曲面另有垂直虛線輔助定位。

標記使用目前姿態的實際求解值，不吸附到最近網格，也不因滑桿移動重新縮放掃描範圍。移動滑桿時保留原有曲面網格、視角、縮放與平移；旋轉 3D 曲面時，點與標籤套用相同投影。前後軸、行程／pose 模式與圖表切換後，標記會使用對應的圖軸座標。PNG、SVG 與 HTML 報告均保留目前標記與數值標籤。

SV 曲面沿用實際 ride height：基準靜態的滑桿行程為前 0／後 0 mm，實際高度為前 50／後 50 mm，前 caster 約 5 deg；標籤同時顯示行程與實際高度。改到前上壓 15、後上壓 −10 mm 時，點移至前 ride height 35、後 60 mm，Z 使用當下 caster 等選定結果。切換 Heave／Pitch 後，點的 X／Y 改為當前 heave 與 pitch。

目前姿態無解、選定數值為 N/A，或超出該圖的掃描範圍時，不保留上一個有效點，也不將點夾到邊界，而是顯示原因。WE 設計 caster 超出 caster 曲面範圍時，該曲面的目前點不顯示，但固定設計 caster 的轉向曲線仍可正常標記。

靜態全車上方的「瞬心／Kingpin 連線與延長線」可一鍵隱藏或顯示瞬心參考線、瞬心與主銷接點組成的參考三角形，以及主銷延長線。切換會保留目前縮放與視角，PNG、SVG 與報告沿用目前顯示設定；硬點資料仍可完整匯出。

FV / SV 的「滑桿 / 曲面座標」選單同時決定掃描座標。FV 可用左右行程或 heave / roll；SV 可用前後 ride height 或 heave / pitch。SV 在前後行程模式下，滑桿控制輪側上壓，曲面橫軸換算成對應 ride height。

### 上壓／下垂行程與角度範圍

掃描設定將行程分為「懸吊上壓行程」與「懸吊下垂行程」，兩格皆輸入非負的 mm 數值。例如上壓 40、下垂 10，表示各輪行程為 −10～+40 mm。兩格各允許 0～200 mm，可將其中一格設為 0，但不可同時為 0。前後 FV、SV 的行程滑桿與掃描範圍共用這組限制；網格保留上下界，跨越零位時也保留靜態 0 mm。

原本的 pitch／roll 範圍欄位用於 Heave／Pitch、Heave／Roll 模式的角度滑桿與掃描，現在已移除手動範圍輸入；兩種姿態操作模式與 pitch／roll 計算結果仍保留。

Heave／Roll 不再有獨立角度上限，直接由左右輪行程控制。Heave 是左右行程的平均；固定 Heave=h、行程上下限為 lo／hi 時，兩輪可用的反向行程為 `±min(h−lo, hi−h)`，再以實際接地點位置計算 Roll 滑桿範圍。改變 Heave 時，原有 Roll 若會使任一輪超行程，就收回新的可達邊界；Heave 到達 lo 或 hi 時，Roll 自然為 0。若連桿幾何先到達不可達位置，也會限制在該幾何分支內。

Heave／Roll 曲面直接掃描完整左右輪行程組合，再轉為實際 Heave、Roll 座標；不再使用固定的角度矩形裁切範圍，因此邊界通常呈菱形或曲邊。各點、目前位置標記與 CSV 均保留相同的左右行程與換算結果。Heave／Pitch 維持由反向行程組合推導參考 pitch 範圍，每個組合再檢查前後輪行程；超限或幾何不可達時標為無解。

參數模式依各軸實際分配的驅動力，自動切換瞬心的兩個設計條件：

| 車軸 | 該軸驅動力比例 > 0 | 該軸驅動力比例 = 0 |
|---|---|---|
| 前軸 | 煞車 Anti-dive＋加速 Anti-lift；SVSA 為唯讀結果 | 煞車 Anti-dive＋SVSA；加速 Anti-lift 為唯讀 0 |
| 後軸 | 煞車 Anti-lift＋加速 Anti-squat；SVSA 為唯讀結果 | 煞車 Anti-lift＋SVSA；加速 Anti-squat 為唯讀 0 |

前軸占比 d=0 的後驅車，僅前軸可直接設定 SVSA；d=1 的前驅車，僅後軸可設定 SVSA；0<d<1 時兩軸都由 Anti 目標求解。這裡的 0 指「沒有分配驅動力」，不是加速 Anti 目標為 0；有驅動力時，0% 加速 Anti 仍可提供一條水平輪心力線。

兩條力線分別從接地點與輪心出發，按煞車／驅動力比例反算斜率 m_B／m_D。零位接地點與輪心垂直對齊時，有號 SVSA=`負載輪胎半徑/(m_B−m_D)`，IC 高度=`m_B×SVSA`。兩線平行或沒有有效有限解時顯示具體錯誤，不會改用保留的 SVSA 代替。SVSA 正值表示 IC 朝另一軸，負值表示朝車頭／車尾外側。

前軸的正 SVSA 不要求加速 Anti-lift 必須為負。令前煞車比例 b、前驅動力比例 d，兩者均大於 0；正 SVSA 的條件為 `加速 Anti-lift < (d/b)×煞車 Anti-dive`。若 IC 低於輪心，前加速 Anti-lift 為負，表示縱向驅動力的幾何效應促進前部抬升；IC 高於輪心則為正，表示抑制抬升。以基準車輛、前煞車 70%、前驅動力 30%、前 Anti-dive 20% 為例，前加速 Anti-lift 須小於約 8.57143% 才得到正 SVSA；−5%、0%、+3% 分別得到約 2.194535、3.474681、5.345663 m。若 Anti-dive=0，正 SVSA 就確實要求加速 Anti-lift<0。程式保留有號 SVSA，未強制只接受正值。

共用設定與 SV／靜態頁左側會自動切換可編輯／唯讀欄位。驅動比例跨過 0 時，會依該軸目前草稿幾何帶入新啟用的 Anti 目標或 SVSA。新帶入的 Anti 目標會取到最接近的 5 個百分點，因此瞬心位置可能隨級距調整。共用設定自動更新預覽；分析頁左側須按套用才更新正式結果。硬點模式全部由原始 XYZ 反算，幾何設計輸入停用。

可編輯輸入框為白底深色字；唯讀計算結果為淺灰底，停用欄位為較深灰底，兩者均保留清楚可讀的文字。比例或硬點模式改變時，顏色會隨可編輯狀態自動切換。

開啟版本 1／2 專案時，依舊公式恢復原本 IC，再轉成新版煞車／加速 Anti 目標與 SVSA，保留原本靜態幾何與硬點；舊「後 Anti-dive」轉為正確的後輪煞車 Anti-lift。版本 1 指定的非零 SVSA 會保留；原本 ±行程轉成相同大小的上壓與下垂，舊 pitch／roll 範圍設定移除。新增前軸驅動力比例預設 0（後驅），應依車輛配置調整。版本 3 保留其驅動比例，依原有煞車目標與 SVSA 算出等效加速 Anti 目標，使幾何保持相同。八個 A 臂 X 設定保持原值。開啟時不改寫原檔，儲存時才寫成版本 4。

JSON 的 `front.anti_lift`／`rear.anti_squat` 保存加速設計目標；`svsa` 保存無驅動力時的備用設計值，有驅動力時不參與求解。報告 `static_parameters` 保存當前真正計算出的 SVSA；硬點模式則保留整組參數模式設計，另記錄硬點反算結果。

掃描預設每軸 21 點，FV / SV 共 441 個組合，解析度可設為 5–51 點。WE 除 caster × steering 網格外，另輸出目前設計 caster 的 steering 曲線。計算在背景執行；改變設定會取消過期結果。不可達姿態會保留錯誤原因，曲面會留空格，CSV 的 `valid` 與 `error` 可用來篩選。

## 單位、座標與計算定義

- JSON 長度一律 m、角度 deg、質量 kg、剛性 N/m；Anti 比例 `0.2` 表示 20%，允許負值或超過 100%。前煞車比例介於 0 與 1；前軸驅動力比例允許 0～1。UI 欄位標示各自單位。
- 靜態全車與 WE：X 向前、Y 向左、Z 向上。WE 顯示右輪 FR / RR，座標原點在前軸中心地面；後軸 X 約為負軸距。WE 正轉角為繞向上主銷的右手正向。
- FV 來源座標：橫向 X 向車右、垂直為 Y，車身座標 CSV 使用 x_m／z_m；動態圖轉為目前接地座標 x′／y′。正行程為輪側接地參考點相對車身向上。正 roll 為右接地點較高。
- FV camber 相對當下左右接地點連線；輪胎上端向外為正。`camber_gain_*_deg_per_mm` 是固定另一輪行程時，該輪 camber 對自身行程的局部偏導，包含地面基準改變；以 ±0.01 mm 中央差分求值。它不同於純 heave 曲線的總斜率。
- SV 來源 X 由前往後，前軸約為 -wheelbase、後軸為 0。正 pitch 為後接地點較高。`ride_height_*_mm = 靜態車底離地高 × 1000 − 對應輪側行程`；此處是 2D 姿態的等效高度，不包含完整車身姿態平衡。
- RC / PC 使用隨接地連線移動、旋轉的座標系：原點在當前兩接地點的中點。FV 的 x′ 由左輪指向右輪，SV 的 x′ 由前輪指向後輪；y′ 是 x′ 逆時針旋轉 90° 的向上法線。因此 y′ 就是到當前接地線的有號垂直高度，x′ 是沿線方向相對中點的位置。計算式為 `x′=(P−O)·u`、`y′=(P−O)·n`。
- 曲面、位置分布與主要數值使用 `rc_x_prime_mm` / `rc_y_prime_mm`、`pc_x_prime_mm` / `pc_y_prime_mm`；另以 `*_world_x_mm` / `*_world_z_mm` 保留固定車身座標作查核。舊版結果的 `rc_x_mm` / `rc_z_mm` 與 `pc_x_mm` / `pc_z_mm` 是固定座標，與新欄位的基準不同。
- FV／SV 動態機構統一畫在目前接地座標 x′／y′ 中。全部連桿、輪胎、CG、RC／PC、零位參考點與座標箭頭均套用同一個平移與旋轉，接地線在圖中為 y′=0；CG 與車身接點會反映升降、roll／pitch。幾何圖維持等比例，滑動時保留縮放與視角。
- FV 圓點標示：粉紅實心 RC、白色大空心 RC0、黃色 CG、青色 IC L、紫色 IC R；均附名稱。RC0 是當前專案零行程的原始 RC；CG 與 RC0 在原始車身座標中固定，在目前接地座標中的顯示位置則會隨車身姿態變動。零行程 RC 與 RC0 重疊時，仍可看見外圈與中心點。SV 同樣標示 PC / PC0、CG 與前後 IC。關閉力線不會隱藏座標軸或圓點。
- SVSA 是接地點至側視瞬心的有號水平距離，並非斜邊長；正值朝另一軸。只有該軸驅動力比例為 0 時可作設計輸入，其餘情況為反算結果。
- `clearance_steer_deg` 是靜態輪圈／避讓構造的設計轉角（原值 36 deg）；與 WE 掃描的 `analysis.steer_deg`（原值 ±30 deg）分開保存。

### 滑桿姿態、CG 與 Anti 的座標基準

滑桿改變輪側行程後，原始運動求解使用固定車身座標；目前前後接地點決定接地原點 O、沿接地線方向 u 與向上法線 n。動態圖使用 `P_contact = R(−pitch) · (P_body−O)`；FV 的 roll 亦採相同轉換。這是同一份幾何的座標轉換，不會修改硬點或把 CG 移出車身。

CG 是車身固定點，因此其車身座標保持設計值；在圖表使用的接地座標中，位置必須隨車身升降與俯仰更新。`cg_x_prime_mm`、`cg_y_prime_mm` 為當前位置，`cg_height_mm` 即 CG 至接地線的有號垂直距離。基準車前後輪同時上壓 15 mm 時，CG 離地高度由 301.645151 mm 降至 286.645151 mm。接地座標屬道路參考，不能將 CG 鎖定在其固定高度，否則會失去車身 heave／pitch 的效果。

2026-11-04 修正前，Anti 的斜率已使用當前接地座標，但軸距與重心高度仍採初始設定值。現在斜率、接地點間距與 CG 高度均由目前姿態計算：`L_current=|P_rear−P_front|`、`h_current=(CG_body−O)·n`，並用相同參考量計算所有姿態與掃描點。非正 CG 高度或無有限斜率時，Anti 顯示 N/A。[ARD 的動態 Anti 說明](https://docs.appliedracingdynamics.com/setup/kinematics/#anti-dive-anti-lift-and-anti-squat)亦將當前軸距、ride height 與 pitch 下的 CG 高度作為參考量。

車輛設定中的 CG 高度代表零行程設計值，滑桿不會改寫專案設定。煞車與加速的連線起點、力分配與名稱也已分開，定義如下。

### 煞車與加速 Anti 的分開計算

「前軸加速驅動力比例」`vehicle.drive_force_front` 是前軸占全車縱向驅動力的比例 d，後軸為 1−d；0 為後驅、1 為前驅、0.5 表示前後各半。這不是加速度 g 值，也不與 `brake_bias_front` 共用。此簡化模型直接輸入輪胎端驅動力占比，不另由扭矩、傳動比與輪胎半徑換算。

令 b 為前煞車比例，L／h 為當前軸距與 CG 高度。接地點 CP→IC 的斜率用於輪端煞車；輪心 WC→IC 的斜率用於加速。兩者均先轉到當前接地座標，再以前軸向後、後軸向前為正的有號水平距離計算斜率 m：

| 指標 | 比例公式（乘 100 得 %） |
|---|---|
| 前 Anti-dive（煞車） | b × L/h × m_CP,front |
| 後 Anti-lift（煞車） | (1−b) × L/h × m_CP,rear |
| 前 Anti-lift（加速） | d × L/h × m_WC,front |
| 後 Anti-squat（加速） | (1−d) × L/h × m_WC,rear |

工況與連線起點參照 [ARD 的 Anti 定義](https://docs.appliedracingdynamics.com/setup/kinematics/#anti-dive-anti-lift-and-anti-squat)。本工具使用有號水平距離，IC 移到相反方向時會反轉效果；負值表示 pro-effect，超過 100% 不截斷。無有限 IC、近乎垂直力線或非正 CG 高度時回傳 N/A；未分配驅動力的軸在有效 CG 高度下，其加速 Anti 為 0。

目前假設輪端煞車，未模擬車身側安裝煞車、輪胎縱向抓地極限或動態扭矩分配。硬點模式固定幾何下，改煞車比例僅改煞車 Anti，改驅動力比例僅改加速 Anti。參數模式的 Anti 是設計目標：改煞車或驅動比例時，為維持輸入目標，IC、SVSA 與硬點可能重新求解；跨過 0 時則自動帶入對應幾何條件。

基準專案的前煞車 Anti-dive 為 20%，後煞車 Anti-lift 為 10%，前後 SVSA 約 3.474681／2.984219 m。預設前後驅動力各 50%，零位的加速 Anti 約為 0%。四個指標均提供滑桿姿態、曲面、目前位置標記、CSV 與報告。

## 模型適用範圍

FV 沿用雙圓求交的 2D 四連桿運動，車身上下接點固定，零位統一使用套件內靜態求解器與目前 JSON 專案。每次求解都以凍結零位為基準，防止多次滑動造成累積漂移；反算後會核對實際行程殘差。接點延長線平行時，RC / PC 顯示 N/A。

SV 沿用原 `sus_sv_v4.py` 的 **Au / Al 固定切線路徑**，維持羊角剛性，並以真實接地參考點高度反算行程；不是完整 3D A 臂懸吊運動。Caster 隨羊角姿態與接地線傾角重新計算。Anti 採上述分開的煞車／加速定義，屬幾何承受縱向載重轉移的比例，未解彈簧、阻尼與完整車身動力平衡。

WE 使用靜態全車解出的主銷軸與輪心做 Rodrigues 旋轉，不使用原 WE 腳本另外建立的主銷公式。固定主銷 caster 本身不隨 steering 改變；因此提供「不同設計 caster × steering → 輪軸傾角」曲面，以及固定設計 caster 的水平曲線。

WE 區分兩個點：`material_*` 是零轉角接地材料點隨輪胎剛體轉動的位置；`contact_*` 是旋轉後、以負載半徑建模的輪胎中心圓最低點。前者到固定主銷的垂距理應恆定，後者的選點改變才會產生半徑變化。圖中的輪胎外形保留自由半徑；未求解有限胎寬的胎肩接觸、彈性變形、轉向頂升平衡，也未將 FV / SV 行程與 steering 耦合成完整 3D 懸吊求解。

在前 FV、後 FV、SV 側視或靜態全車頁，按底部「STEP 線框」存成 `.step`。檔案使用與 VehicleLab 相同的 AP214 線框格式，單位為 **mm**，適合匯入 CAD 作為建模參考。座標固定於車身，X 向前、Y 向左、Z 向上。前、後 FV 分別位於各軸 X 平面，SV 位於 Y=0。FV／SV 使用目前滑桿姿態，並依「顯示 IC / 力線參考」決定是否納入這些參考線。

靜態全車輸出已套用設計的 3D 連桿中心線。參數模式採用計算出的 A 臂接點（包含手動指定的 X），硬點模式採用專案的 XYZ。四輪連桿可匯入同一份 CAD 檔案，旋轉視角或開關 FV／SV 顯示平面時，STEP 座標保持一致。

CSV 使用 UTF-8 BOM，可直接以 Excel 開啟。`*_mm`、`*_deg`、`*_pct`、`*_m` 與 `*_deg_per_mm` 表示欄位單位；`axis_x` / `axis_y` 是所選掃描座標，SV 行程模式為換算後前 / 後 ride height。曲面圖會標示座標與單位。

FV / SV 硬點 CSV 的 `x_m` / `z_m` 是固定車身座標，`x_prime_m` / `y_prime_m` 是當前接地中點座標，與動態圖中的點位一致，包括 CG。姿態／範圍 CSV 另有 `cg_height_mm`、`cg_x_prime_mm`、`cg_y_prime_mm`，SV 包含 `wheelbase_mm`。報告的輸入快照另存接地座標原點與兩個單位基底；PNG / SVG 與報告使用同一份接地座標圖形。
