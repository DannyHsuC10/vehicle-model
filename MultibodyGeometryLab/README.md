# MultibodyGeometryLab 四輪多體幾何工作台

工作台依車輛參數或硬點座標建立四輪雙 A 臂的靜態幾何及固定桿長。可指定行程與轉向來求運動學，也可加入直推避震器、輪端質量與輪胎接地力，模擬路面擾動下的車身與四輪響應。

## 啟動

需要 Python 3.10 以上、Tkinter 和 NumPy。整個 `MultibodyGeometryLab` 資料夾可單獨移動或複製，靜態幾何、參數驗證與預設專案都包含在其中。在 Windows 雙擊 `Start-MultibodyGeometryLab.bat`，或從 `MultibodyGeometryLab` 的上一層執行以下指令。

一般啟動會載入 `new/suspension_geometry.json` 的內建副本。可用 `--project` 指定其他專案。

```powershell
python -m pip install -r MultibodyGeometryLab/requirements.txt
python -m MultibodyGeometryLab
python -m MultibodyGeometryLab --project MultibodyGeometryLab/projects/Example.json
```

## 編輯與計算

1. 在「車輛」「前軸」「後軸」修改尺寸、輪胎和懸吊設計。前、後軸頁也可設定轉向拉桿的內外側接點，輸入相對輪心的 XYZ 偏移量。按「解算靜態」更新零位、四輪座標與桿件長度。
2. 若已有實測硬點，在「硬點」勾選「用硬點 XYZ 定義幾何」，再雙擊編輯。四輪各有六點，上、下 A 臂各含兩個車身接點及一個球接點。編輯一側會鏡射到另一側。可按「由目前參數重建 24 點」更新硬點草稿。
3. 在「工況」填入四輪輪心的垂直位移、速度、加速度，以及前、後齒條的橫向位移、速度、加速度。按「解算工況」查看結果。右側可以切換至靜態或工況姿態，並查看四輪摘要、單輪各節點的 XYZ 運動及各條約束的長度誤差。3D 視圖可拖曳旋轉、用滾輪縮放，也可切換前視、側視與上視。
4. 「儲存 JSON」保存目前表單值，「另存 JSON」建立另一個設計版本。「開啟 JSON」可載入本工具的專案，或匯入完整的 SuspensionGeometryLab 專案。匯入既有懸吊專案後，首次儲存需選擇本工具的檔案路徑。

若行程超出可達範圍或 Jacobian 接近奇異，介面會指出無法解算的輪位並顯示靜態幾何。可先減少輪心行程或齒條位移，並從「固定桿長／誤差」查看收斂結果。

## 3D 動畫

在左側「動畫」頁選擇標準工況，設定幅度與週期，再按「解算並播放」。預設一個週期為 3 秒，可改為 0.5～12 秒。3D 視窗下方可播放、暫停、停止或拖曳時間軸。拖曳時間軸會暫停，方便檢查該格的輪心、轉向角及桿長。取消「循環播放」時，播放到週期末即停止。

| 工況 | 預設幅度 | 動作 |
| --- | --- | --- |
| 單輪抬升 | 25 mm | 車身固定，所選輪心抬升後回到零位，可選 FL、FR、RL、RR。 |
| 全車升降（Heave） | ±20 mm | 車身相對地面上下平移，四輪輪心維持各自的靜態地面高度。 |
| 全車側傾（Roll） | ±2° | 車身繞通過重心的 X 軸左右側傾，四輪輪心維持各自的靜態地面高度。 |
| 前輪轉向 | ±8 mm | 前齒條沿 Y 軸往復，前輪依固定長度的轉向拉桿轉動。 |

動畫從靜態零位開始，以平滑軌跡往復並在週期末回到零位。每格重新求解固定桿長與 Jacobian。畫面採地面座標，虛線車身是靜態參考。結果表的位置、速度、加速度、轉向角與外傾角採車身座標。以輪心高度作為升降及側傾的幾何參考。輪胎接地力和變形屬動力模型。

工況、輪位、幅度、週期與循環設定會寫入專案 JSON 的 `animation` 欄位。既有 JSON 開啟時會自動帶入單輪抬升預設。特定幾何下若某格不可達，視窗會顯示失敗時間和輪位，可縮小幅度再試。

## 桿件角運動與 2D 訊號圖

在 3D 視窗下方選擇結果輪位，再切到「桿件角運動」。每輪 11 條桿件約束都會顯示從端點 A 指向 B 的車身座標方位角、仰角、距靜態方向的夾角，以及三軸角速度與角加速度。方位角從 +X 朝 +Y，仰角向上為正。桿軸若與 Z 軸平行，方位角欄會顯示「—」。

上下 A 臂的角速度及角加速度沿已知鉸鏈軸。可在「A 臂鉸鏈」查看相對靜態的有號轉角及其導數，正向沿車身前接點指向後接點。羊角約束邊使用羊角剛體的角運動。轉向拉桿只有兩端接點，因此角速度及角加速度描述桿軸方向的變化，繞桿長軸的自旋需要額外的姿態約束才能求解。

解算一段動畫後，按 3D 視窗上方的「2D 訊號圖」開啟曲線視窗，再選輪位、節點、桿件或 A 臂鉸鏈與訊號。節點可選 XYZ 位置、速度及加速度，桿件可選方向角、角速度或角加速度。曲線橫軸是秒，數值採車身座標。方位角曲線連續展開，跨過 ±180° 時保持平滑。播放時游標與 3D 同步。點選或拖曳曲線區可暫停並查看最接近該時間的求解姿態。

## 直推避震器與輪端動力學

1. 在左側「動力學 → 輪端／路面」逐輪設定輪端質量 (kg)、彈簧剛性 (N/m) 和避震器阻尼 (N·s/m)。質量集中在輪心，可填入輪胎、輪圈和其他要一併計算的輪端質量。預設每輪為 10 kg、30,000 N/m 和 1,300 N·s/m。
2. 在「前軸」和「後軸」各自的「Push Rod 車身接點」輸入左側 Y（非負）與左右共用的 Z，共四欄，單位為 mm。右側 Y 為左側的相反值，各輪車身端 X 自動取各自靜態 `UBJ`（羊角與上 A 臂共接點）的 X。輪端固定接在 `UBJ`。可用 Y、Z 調整斜度，懸吊作動時車身端仍固定在車身座標。首次開啟基準專案會填入靜態 UBJ 正上方 250 mm 的接點。
3. 選單輪或四輪作為路面擾動對象，設定高度、擾動持續時間與模擬時間，再按「模擬並播放」。高度為負值可模擬凹陷，填零可檢查靜態平衡。車身會隨輪胎與懸吊受力平移及轉動。右側「避震器」顯示各輪伸縮與受力，「車身接點力」顯示所選輪位傳到車身的力。

在「輪端／路面 → 輪胎垂直接地」可一起設定四輪共用的輪胎垂直剛性（N/m）和垂直阻尼（N·s/m）。剛性欄與「車輛」頁同步，靜態負載半徑及動力接地力使用同一個剛性值。

避震器兩端的距離和桿軸方向隨姿態重新計算，彈簧阻尼的作用力沿當下桿軸，解算會使用其方向以及隨姿態變化的行程比。右側「避震器」表和「2D 訊號圖 → 避震器」可查看相對車身垂直軸的傾角與車身座標中的車身端 XYZ 力。「車身接點力 → 避震器車身端」可查看地面座標的力。長度變化以靜態安裝長度為零，正值代表伸長，負值代表縮短。

各輪上下 A 臂的前後車身鉸鏈、齒條側接點和避震器車身端都固定於同一個剛體的車身座標，隨車身一起平移、轉動。指定工況和運動學動畫同樣可查看避震器長度、傾角和彈簧阻尼力。

彈簧自由長度由靜態輪荷、輪端重量與接點行程比配算，使模擬從平衡開始。輪胎以相對地面的輪心高度及速度計算單向正向力，離地時正向力為零。簧上車身與四輪輪端皆受重力。接點力由實際桿長約束反算，以地面座標表示，包含上下 A 臂四個車身端、齒條側接點與避震器車身端。

接點的四個數值以 `dynamics.pushrod_mounts.front` 與 `dynamics.pushrod_mounts.rear` 的 `y_mm`、`z_mm` 存入專案，四輪質量、剛性與阻尼另按輪位儲存。工作台開啟舊的逐輪接點專案時，會取左前、左後車身端的實際 |Y|、Z 初始化兩軸欄位，再依新定義鏡射右側與對齊靜態 UBJ 的 X。

## 編輯機構元件

在左側「機構元件」選擇輪位，點圖上的線條或清單，將元件分類為「剛性桿」或「彈簧阻尼」。可按「全車設為剛性」從全剛性線條開始，再把選定的元件改成彈簧阻尼。也可以選兩個既有接點新增連線，或移除選取的連線。Push Rod 保留 DAMPER–UBJ 連線，可切換類型。

剛性桿以靜態幾何的長度加入約束。彈簧阻尼使用當下長度與速率計算沿桿軸的力，k、c 留白時沿用該輪設定。按「套用機構」後，再進行路面模擬或播放動畫。「2D 訊號圖 → 彈簧阻尼」可按元件看桿長、伸長、速度與軸向力。修改後的元件清單隨 JSON 存入 `dynamics.elements`。

目前每輪支援以輪心垂直行程表示的單一自由度，以及固定桿把相對輪端鎖定的配置。全剛性時，路面模擬仍會計算輪胎變形和車身姿態。若把原有剛性桿改成彈簧後，產生額外的獨立運動或輪心行程無法獨立控制，程式會指出輪位，可檢查是否該補上其他剛性連線。這裡的剛性桿是兩接點間的固定距離約束。

## 車身轉動慣量

在「車輛 → 車身轉動慣量」輸入簧上車身繞重心的 Ixx、Iyy、Izz，分別對應 X 側傾、Y 俯仰、Z 偏航，單位都是 kg·m²。預設 55、95、125 kg·m² 是可修改的起始值，假設車身座標軸為慣量主軸。舊專案會帶入這組值，存檔時寫入 `dynamics.chassis_inertia`。

「輪端／路面」聯立車身三軸平移與三軸轉動，以及各輪相對車身的行程。車身繞簧上重心轉動，簧上重心位置由整車重心與四輪輪端質量配算。轉動方程使用隨姿態轉換的慣量張量，並計入角速度產生的陀螺項。輪端仍以集中質量表示，地面接觸力沿垂直方向。3D 可直接看側傾、俯仰與偏航，「2D 訊號圖 → 車身」可追蹤角度、角速度與角加速度。

## 重心受力與車身 Heave

在「動力學 → 重心 Heave」輸入向下力、施力上升時間與模擬時間，再按「模擬重心 Heave」。輸入正值向下，負值向上。預設 600 N 在 0.25 秒內平滑增加到目標值，此後維持到模擬結束。這個工況的地面固定在 Z = 0，車身只沿 Z 軸平移，求解器同時積分車身和四輪運動，輪胎接地力由相對地面的輪心高度和速度計算。車輛總質量扣除四輪輪端質量即為車身質量；兩者皆受「車輛」頁設定的重力。計算由含輪胎靜態壓縮與避震器預壓的零位開始。設定會隨專案寫入 `dynamics.heave`。

在「2D 訊號圖 → 車身」可看重心 Z 位移、速度、加速度及外力，地面座標 +Z 向上。比較「避震器 → 相對靜態伸長」時，負值表示避震器縮短。

可用 600 N、0.05 秒上升時間和 3 秒模擬時間觀察零阻尼震盪。在「輪端／路面」將四輪避震器阻尼和輪胎垂直阻尼全部設為 0。在輪胎維持接地且外力穩定後，重心應繞著受力後的平衡高度持續震盪。若輪胎垂直阻尼大於零，它仍會耗散震盪能量。

## 座標與 JSON

- 車輛採 X 向前、Y 向左、Z 向上。前軸 X 為 0，後軸 X 為負軸距。輪心上壓為正，齒條向左平移為正。同一車軸的左、右內側接點使用同一個齒條位移。
- A 臂硬點和車身接點 X 在介面以 mm 編輯。拉桿偏移同樣以 mm 編輯，但 Y 採每輪向外為正，兩側在車輛座標中互為鏡射。四輪工況的位移、速度和加速度以 mm、mm/s、mm/s² 輸入。角度以度顯示，羊角角速度及角加速度以 rad/s、rad/s² 顯示。
- 專案頂層含有 `format`、`schema_version`、`geometry`、`steering`、`motion`、`animation` 和 `dynamics`。其中 `geometry` 使用 SuspensionGeometryLab 格式，長度以 m 保存。`steering` 的前後軸內外側接點偏移也以 m 保存，`motion`、`animation` 和 `dynamics` 使用各自介面標示的單位。
- 匯入的 `static_camber_deg`、`roll_stiffness_ratio` 與 `kinematics_hardpoints` 會隨專案保留。多體解算仍使用工作台內的輪軸零位、避震器與轉向接點設定。
- 前、後軸預設的轉向拉桿接點是範例座標，可改成實車量測值。初始輪軸方向沿全車 Y 軸，結果中的轉向角和外傾角以此為零位。

## 求解假設

指定單一工況時車身固定。升降與側傾動畫使用已知的車身運動，在地面座標約束輪心高度。基準配置中，每輪上下 A 臂以球接點到兩個車身硬點的距離定義，羊角由上下球接點、輪心和外側拉桿接點組成剛體，拉桿長度在工況求解時保持靜態值。套用自訂機構後，求解器依目前的固定桿長約束組裝 Jacobian。

位置解從靜態位形逐步追蹤到指定工況。各桿件約束採平方距離形式，除以靜態長度以改善數值尺度。速度與加速度由約束方程的一階與二階時間微分求得，包含移動齒條及桿件相對速度的二階項。每筆結果描述指定位移、速度、加速度對應的瞬時運動。外力、質量慣性、彈簧阻尼力與輪胎接地反力屬於動力學模型。
