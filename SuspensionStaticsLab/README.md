# Suspension Statics Lab 懸吊靜力分析

在固定的原始硬點幾何上求解懸吊桿件的拉力與壓力。桿件的截面與材料會用於計算軸向應力、應變及伸縮量。

## 操作方式

1. 在 Windows 雙擊 `Start-SuspensionStaticsLab.bat`。啟動時會顯示四輪範例和靜態負載的應力色階。從車輛工具根目錄也可執行 `python -m SuspensionStaticsLab`。需要 Python 3.10+、Tkinter 及 `requirements.txt` 內的 NumPy。
2. 按「匯入硬點 CSV」載入座標。按「編輯硬點 XYZ」可逐列修改 mm 座標，並可另存為 CSV。編輯後按「套用並關閉」更新幾何；若要依新座標重算範例輪荷，請重新套用範例。
3. 在「外載工況」套用範例，或選擇「硬點 XYZ 外力」並新增一組 `Fx, Fy, Fz`（N）。多列外載會相加。可選取一列再更新或刪除。「桿端 A 力矩」和「桿端 B 力矩」接受 `Mx, My, Mz`（N·m），以右手定則把外部力偶施加在所選桿端所連的剛體上。介面會顯示端點與剛體名稱。力偶由該剛體相連的桿件軸力及支承反力平衡；單支二力桿只能沿桿軸傳力。
4. 按「求解桿件受力」。結果依應力絕對值排序，表內保留拉壓符號。左側可拖曳旋轉平移、用滾輪縮放，或切換正交視角。輪胎以透視線框示意；實線為求軸力的桿件，虛線為剛體幾何。
5. 在「桿件截面」的下方表格選取桿件。按住 Ctrl 點選可複選個別桿件，按住 Shift 點選可選取連續範圍。設定外徑、內徑（mm）及楊氏模數（GPa）後，按「套用至選取桿件」更新所有選取的桿件，或按「套用至全部」更新全車。截面圖和截面性質隨內外徑輸入更新。預設為外徑 19 mm、內徑 15 mm、E = 205 GPa 的示例圓管。內徑為 0 可定義實心圓桿。已有軸力結果時，套用截面後會更新應力、應變、伸縮量和色階。

外載的 XYZ 輸入框旁會即時顯示合力或合力矩的大小。套用後，重心、各輪接地點和其他外載列的大小顯示在「合量」欄，單位依該列型態。表格上方會把已套用的力按 XYZ 分量相加並顯示總合力大小，純力矩只影響力矩平衡。

## 硬點 CSV

UTF-8 CSV 使用 `name,x_m,y_m,z_m` 或 `name,x_mm,y_mm,z_mm`。也接受 `point` 欄和選填 `corner` 欄，例如 `FL,UBJ`。+X 朝前、+Y 朝左、+Z 朝上。四個輪位以 `FL_`、`FR_`、`RL_`、`RR_` 開頭；單輪資料可省略前綴。

| 硬點 | 用途 |
| --- | --- |
| `UCA_F`、`UCA_R`、`LCA_F`、`LCA_R` | 車身固定的上下 A 臂前後內端。亦接受 `UFI`、`URI`、`LFI`、`LRI`。 |
| `UBJ`、`LBJ` | 羊角的上下球接點。一般 A 臂由兩支共用外端的軸力桿表示。 |
| `RACK`、`TOE` | 轉向拉桿的車身固定端和羊角端。亦接受 `ROD_IN`、`ROD_OUT`。 |
| `WC`、`CONTACT`、`FORWARD` | 羊角所帶的輪心、接地點與選填輪向。缺接地點時會建立輪心下方的示意接地點，可在介面編輯。`WHEEL_CENTER` 亦可作為輪心。 |
| `PUSH_IN`、`PUSH_OUT_UPRIGHT` | 推桿接羊角的配置。外端也可用 `PUSH_OUT`（下 A 臂）或 `PUSH_OUT_UCA`（上 A 臂）。推桿接 A 臂中段時，該 A 臂與車身的連接按剛體及鉸鏈建模，並由球接點將力傳給羊角。該臂的兩條虛線為剛體外形。 |
| `ROCKER_A`、`ROCKER_B`、`DAMPER_IN`、`DAMPER_BODY` | 齊備時，使用可繞軸轉動的剛性搖臂和軸向阻尼器。`DAMPER_IN` 在搖臂上，`DAMPER_BODY` 固定在車身。資料不全時，推桿內端固定於車身。 |
| `CG`、`COP` | 全車重心、空力下壓作用點。四輪範例會補上缺少的座標，並可在硬點編輯器內調整。 |

內建的 [硬點 CSV](examples/hardpoints.csv) 取自工作區的四輪基準幾何，將推桿外端連到羊角，並加入示例阻尼器硬點，每輪共七支軸力桿。可直接匯入 JacobianKinematicsLab 的硬點 CSV，依原有命名建模。只有幾何定位點的 CSV 仍可預覽；求解輪荷時，需提供完整受力路徑及車身支承。

## 範例工況

| 工況 | 預設值 |
| --- | --- |
| 靜態負載 | 321 kg 車重與四輪正向接地反力。 |
| 重心加速 | 可輸入重心質量與三軸加速度，預設 321 kg、`ax = 6.3765`、`ay = 0`、`az = 0`，加速度單位為 m/s²。 |
| 單輪受衝擊 | 第一個可用輪位在接地點承受 1800 N 的 +Z 等效峰值，作為獨立載荷。 |
| 空力下壓 | 321 kg 車重加上 COP 處 800 N 下壓。預設 COP 位於對應前軸 45% 分攤的縱向位置。 |

選「重心加速」後填入質量與 `ax`、`ay`、`az`。「計入重力」預設勾選，會加上向下的 `g = 9.81 m/s²`。如需只計算輸入的加速度，可取消勾選。按「套用範例」更新載荷表，再按「求解桿件受力」。三軸都為 0 時，勾選會產生靜態輪荷，取消勾選則為零載荷。

「輸入合加速度」即時顯示 `√(ax² + ay² + az²)`，單位為 m/s²。重力依勾選狀態另外計入載荷。

只看平路轉彎時可將 `ax` 和 `az` 設成 0，例如 `ay = 8.3385` 表示向左 0.85 g。`az` 向上為正。重心加速以 `−m(ax, ay, az)` 和勾選的重力作為重心等效外力，依硬點分配四輪接地反力。勾選時輪胎正向力合計為 `m(g + az)`，取消勾選時為 `m·az`。前後及左右載重轉移由固定姿態的力矩平衡求得，分配屬範例平衡解。若需要負的輪胎正向力，介面會提示輪胎離地。接地力可逐列替換為指定值或實測值。

## 圓形截面性質

截面圖依直徑比例顯示。下表的 `Dₒ` 為外徑，`Dᵢ` 為內徑，`c = Dₒ/2` 為最外緣距離。`I` 與 `S` 適用於任何通過圓心的直徑軸，極截面性質以圓心為準。

| 性質 | 公式 | 單位 |
| --- | --- | --- |
| 截面積 A | `π(Dₒ² − Dᵢ²)/4` | mm² |
| 截面二次矩 I | `π(Dₒ⁴ − Dᵢ⁴)/64` | mm⁴ |
| 截面係數 S | `I/c` | mm³ |
| 截面迴轉半徑 r | `√(I/A)` | mm |
| 極慣性矩 J | `2I` | mm⁴ |
| 極截面係數 Zₚ | `J/c` | mm³ |
| 極迴轉半徑 rₚ | `√(J/A)` | mm |

軸力平衡使用硬點幾何。軸向應力、應變和伸縮量使用截面積與楊氏模數，其餘截面性質供查閱。

## 自訂拓撲

任意點名可搭配拓撲 JSON。先匯入 CSV，再按「載入拓撲 JSON」。`fixed` 裡的硬點固定於車身，`bodies` 把一組硬點歸到共同的剛體。沒有指派到車身或剛體的桿端視為只傳三軸力的鉸接節點。各支 `rods` 需有唯一名稱與兩個 CSV 端點。以下為原點鉸接節點加三支正交桿的例子，對 `joint` 加力可驗證拉壓方向。

```json
{
  "fixed": ["anchor_x", "anchor_y", "anchor_z"],
  "bodies": {},
  "rods": [
    {"name": "X", "a": "joint", "b": "anchor_x"},
    {"name": "Y", "a": "joint", "b": "anchor_y"},
    {"name": "Z", "a": "joint", "b": "anchor_z"}
  ]
}
```

## 計算定義

- 對每個剛體求 `ΣF = 0` 與 `ΣM = 0`，鉸接節點求 `ΣF = 0`。每支桿的未知數 `P` 沿原始端點連線，`P > 0` 為拉力、`P < 0` 為壓力。若平衡式給不出唯一內力，或外載無法平衡，介面會顯示矩陣秩及原因。
- 截面積 `A = π (Dₒ² − Dᵢ²) / 4`，軸向應力 `σ = P/A`，軸向應變 `ε = σ/E`，線彈性伸縮量 `ΔL = PL₀/(AE)`。圖上以當前工況的 `|σ|` 由藍漸紅。變形量採求解前的原始桿長，並保留伸長或縮短的符號。
- 這是固定幾何的軸力平衡與線彈性後處理。應變及伸縮量僅供讀值，幾何始終顯示原始座標。壓桿挫屈及 A 臂彎曲需額外做結構分析。
