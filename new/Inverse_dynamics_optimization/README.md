# 機構最佳化分析
## [反向動力學求解器](Model_Analysis/Inverse_kinematics.md)
多體動力學系統設計的逆運動學求解工具，旨在協助進行機構的最佳化分析與模擬。該工具整合了多個核心引擎，提供從靜態受力約束求解到動態模擬的完整解決方案。內部有可以分成以下幾個子項目 :
1. 反向動力學引擎 : 進行多體系統、靜力學、材料力學、運動學、虛功計算
1. 模擬器 : 整合視覺化、求解、資料驅動、輸出
1. UI: 方便進行使用提供介面操作

## [最佳化工具](Optimization/Optimizer.md)
整合 L-BFGS-B、差分進化、CMA-ES 等多種數學優化方法，支援非凸與高維度問題的全域搜尋。搭配空間邊界條件定義工具，與最佳化模組方便地進行最佳化工作。
