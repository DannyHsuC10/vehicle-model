# Material_engine 材料力學分析引擎

## 1. 材料分析概述

`MaterialEngine` 是一個專門用於計算結構中桿件材料特性的分析工具，它基於靜力求解結果，計算應力、應變、變形、剛度和應變能，並進行結構安全檢驗。

### 1.1 設計原則

- **依賴注入**：接收 `AnalysisState` 對象，無需內部狀態管理
- **無副作用**：只讀取求解結果，不修改求解過程
- **完整性**：同時更新狀態字典和桿件屬性對象
- **安全檢驗**：自動計算安全係數和失效標誌

### 1.2 核心類

```python
class MaterialEngine:
    """材料分析引擎"""
    def compute(self, state):
        """對所有活躍桿件進行材料分析"""
        
class AnalysisState:
    """分析狀態容器"""
    def __init__(self, nodes, rods):
        """初始化分析狀態"""
```

## 2. 理論基礎

### 2.1 一維彈性桿理論

假設桿件滿足以下條件：

- **一維性**：長度遠大於截面尺寸
- **齊次性**：材料性質沿長度方向均勻
- **等截面**：截面積沿長度方向不變
- **小變形**：變形量遠小於桿件長度（$|\Delta L| \ll L_0$）
- **二力桿**：只在兩端受力，內力沿桿件軸向

### 2.2 基本假設

1. **平面截面假設**：桿件截面保持平面，不發生彎曲
2. **均勻應力分佈**：應力在截面內均勻分佈
3. **Hooke定律**：應力與應變成線性關係
   $$\sigma = E \cdot \varepsilon$$

### 2.3 內力來源

內力 $F$ 來自前驅靜力求解步驟：

$$F = \text{StaticAnalyzer.solve() 的結果}$$

- 由節點外載荷和約束條件決定
- 在靜態平衡條件下是唯一確定的（適定系統）

## 3. 材料計算公式

### 3.1 應力計算

**定義**：單位截面積上的內力

$$\sigma = \frac{F}{A}$$

**物理意義**：
- 代表材料受到的強度（應力程度）
- 大應力→容易失效
- 單位：MPa（N/mm²）或 Pa

**計算實現**：

```python
stress = F / A
```

其中：
- $F$：桿件內力（N）
- $A$：截面積（mm²）

**應力分類**：
- **拉應力** ($\sigma > 0$)：桿件受拉
- **壓應力** ($\sigma < 0$)：桿件受壓

### 3.2 應變計算

**定義**：材料的相對變形程度

根據 Hooke 定律：

$$\varepsilon = \frac{\sigma}{E} = \frac{F}{A \cdot E}$$

**物理意義**：
- 無量綱量（純數字）
- 代表變形相對於原始尺寸的比例
- 小於 0.01 表示小變形

**計算實現**：

```python
strain = F / (A * E)
```

其中：
- $E$：楊氏模量（MPa），材料剛度的度量

### 3.3 變形量計算

**定義**：桿件實際伸長或縮短的距離

$$\Delta L = \varepsilon \cdot L_0 = \frac{F \cdot L_0}{A \cdot E}$$

**物理意義**：
- 絕對變形值（有量綱）
- 可用於驗證配合間隙
- 單位：mm

**計算實現**：

```python
delta_L = strain * L0
```

### 3.4 剛度計算

**定義**：單位變形所需的力

$$k = \frac{A \cdot E}{L_0}$$

**物理意義**：
- 剛度高→少變形
- 剛度低→易變形
- 單位：N/mm

**計算實現**：

```python
stiffness = (A * E) / L0
```

**應用**：
- 機構的整體剛度由所有桿件共同決定
- 在動力學中用於模態分析

### 3.5 應變能計算

**定義**：桿件內儲存的彈性勢能

$$U = \frac{1}{2} \cdot F \cdot \Delta L = \frac{F^2 \cdot L_0}{2 \cdot A \cdot E}$$

**物理意義**：
- 代表結構的「彈性儲存」
- 卸載後可完全回復
- 單位：J（焦耳）或 N·mm

**計算實現**：

```python
energy = (F**2 * L0) / (2 * A * E)
```

**應用**：
- 結構總應變能用於優化判據
- 在虛功原理中用於力的計算

## 4. 安全檢驗

### 4.1 安全係數

**定義**：最大允許應力與實際應力的比值

$$n_s = \frac{\sigma_{\max}}{|\sigma|}$$

**判斷標準**：

| 條件 | 意義 |
|------|------|
| $n_s > 1$ | 安全，結構有安全裕度 |
| $n_s = 1$ | 臨界，恰好達到極限 |
| $n_s < 1$ | 失效，應力超過材料承載能力 |

### 4.2 失效判定

```python
if r.max_stress > 0:
    r.safety_ratio = abs(stress) / r.max_stress
    r.fail = abs(stress) > r.max_stress
else:
    r.safety_ratio = None
    r.fail = False
```

**邏輯**：
- 若未定義 `max_stress`（≤0），跳過檢驗
- 若應力超過 `max_stress`，標記為失效



## 5. 驗證與測試

### 5.1 單杆拉伸驗證

**測試配置**：
- 單根桿件，一端固定節點
- 在一端施加拉力

**預期結果**：
$$\sigma = \frac{F}{A}, \quad \varepsilon = \frac{F}{A \cdot E}, \quad \Delta L = \frac{F \cdot L_0}{A \cdot E}$$

### 5.2 應能守恆檢驗

對於系統總應變能：

$$U_{\text{total}} = \sum_i U_i$$

與外力做功比較：

$$W_{\text{ext}} = \mathbf{F}_{\text{ext}} \cdot \mathbf{\Delta}$$

在小變形下應滿足：$W_{\text{ext}} \approx 2 U_{\text{total}}$
