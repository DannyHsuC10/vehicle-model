# SuspensionSetupLab｜懸吊調校

在同一工況比較兩組車輛設定，觀察各輪輪荷、行程、姿態、限位與元件的力和速度。全車、半車與單輪模型共用 `new/dynamics_analyze` 的模態通道和可替換 KC 元件架構，介面與線性專案匯入延續 SuspensionDynamicsLab 的工作方式。

雙擊 **Start-SuspensionSetupLab.bat**，或在此資料夾執行 `python -m setup_lab`。需要 Python 3.10+、Tkinter 與 NumPy。實車 3D 使用 PyVista，請用啟動程式的同一個 Python 環境安裝下列依賴。整個資料夾可獨立複製使用。

```powershell
python -m pip install -r requirements.txt
python -m setup_lab --project examples/staged-setup.json
python -m setup_lab --project examples/staged-setup.json --csv staged-result.csv
python -m unittest discover -s tests -v
```

## 調校流程

1. 在「車輛與輪胎」填入總質量、重心、簧上慣量與每輪簧下質量、輪胎垂直剛性及阻尼。開啟「全車」、「1/2 左右」、「1/2 前後」或「1/4 車」頁籤，再選模型適用的輪位、車軸或側別。
2. 在「彈簧與阻尼」選擇通道，設定前後升沉、前後側傾、同向側傾、對角扭擺或 FL／FR／RL／RR 直推。各通道可獨立啟用及編輯。表格會標示目前模型用到的通道。可用「預覽元件曲線」檢視彈簧、限位、阻尼與 MR。
3. 選擇目前模型適用的工況，或載入量測 CSV。各頁皆可選 ISO 8608 Class A、B、C。全車與 1/2 前後模型可對選中的後輪套用輪跡延遲。按 **F5** 計算。
4. 在「視覺化」播放、逐格或拖曳時間滑桿。全車頁左側顯示四輪法向輪荷、各輪懸吊通道合力、六組模態通道力、四輪直推力與車身姿態。懸吊通道合力由模態與直推通道投影到輪端後加總，停用通道顯示「—」。右側可切換「LP02 實車 3D」和「曲線」，兩者與監控面板共用同一條時間軸。拖曳實車畫面可旋轉，滾輪可縮放。1/2 左右使用前視動畫，1/2 前後與 1/4 車使用側視動畫，亦可切換至輪荷與姿態儀表板。拖曳分隔線可調整兩邊寬度。
5. 按「設目前結果為 A」，編輯參數或開啟另一份專案，再用相同模型、模型輪位、工況及輸出間隔重算 B。曲線以虛線標示 A，指標頁顯示最低輪荷及車身升沉加速度 RMS 的差值。動畫與儀表板顯示目前結果。
6. 「匯出 CSV」輸出目前頁的結果。「儲存計算快照」另存該次計算的工況與參數。專案 JSON 可透過 Ctrl+O／Ctrl+S 開啟與儲存，包含四個分析頁的模型、工況及匯入的路面資料。開啟舊專案時，原本的「1/2 車」工況會放到對應的左右或前後頁。切換分析頁時，會暫停播放並保留各頁的結果與 A 基準。結果與 A 基準保留在本次開啟的程式中，可用 CSV 和計算快照留存。

可匯入 SuspensionDynamicsLab 的 `parameters.full` 專案及 VehicleInitialSizingLab 的 Dynamics JSON。線性係數會換算成介面的 N/mm 與 N·s/m，輪胎會換算到輪端，舊工況使用新工具預設值。來源若標記 Tender 但缺少併圈行程及安裝條件，會保留來源的線性剛性並顯示備註，供使用者在元件頁補齊。

LP02 視圖直接載入 `assets/LP02/` 內的車體與四輪 STL，保留 CAD 尺寸及輪位，以每次模擬的初始平衡狀態對應 CAD 靜態姿態。車身顯示升沉、俯仰和側傾，8 DOF 模式將前後側傾沿車身長度插值以呈現扭轉。四輪各自使用簧下垂向位移。轉向、外傾與車輪自轉需要額外的模型自由度。

## 模型與通道

| 模型 | 自由度與輪位 | 使用的通道及工況 |
| --- | --- | --- |
| 1/4 車 | 2 DOF，簧上與簧下升沉。選 FL、FR、RL 或 RR。 | 同軸等效升沉與該輪直推。支援凸塊／凹坑及單輪路面回放。 |
| 1/2 左右 | 4 DOF，車身升沉、側傾及兩輪簧下升沉。選前軸或後軸。 | 該軸升沉、側傾與兩輪直推。支援路面、側向加速度與組合工況，含該軸側傾中心傳力。 |
| 1/2 前後 | 4 DOF，車身升沉、俯仰及前後輪簧下升沉。選左側或右側。 | 前後等效升沉及同側直推。支援路面、縱向加速度與組合工況，含前後 Anti 傳力與輪跡延遲。 |
| 全車 | 7 DOF 剛性車架或 8 DOF 可扭轉車架。8 DOF 將前後側傾分開。 | 全部通道及工況，含同向側傾、對角扭擺和四輪直推。 |

局部模型的簧上質量由全車重心的前後配重分配，各輪保留原本的簧下質量與輪胎參數。1/2 左右按該軸配重分配側傾慣量，1/2 前後取全車俯仰慣量的一半。1/4 與 1/2 前後的升沉通道採同軸左右對稱等效，元件依兩倍單輪行程計算，保留該元件的分段門檻，求出的反力施於該輪。1/2 左右依兩輪各自的行程計算升沉與側傾。跨軸的同向側傾及對角扭擺由全車模型計算。[1/2 前後自由度與模型](https://doi.org/10.3390/2571-631X/7/4/55) · [1/2 左右與單軸互聯懸吊](https://journals.sagepub.com/doi/10.1177/09544070251395345)

## 元件曲線與單位

每行兩欄，第一欄須嚴格遞增，最多 256 列。表格可直接貼上試算表中的兩欄數值。

| 設定 | 第一欄 | 第二欄 | 區段定義 |
| --- | --- | --- | --- |
| 多段剛性 | 起始軸心壓縮行程 mm | 剛性 N/mm | 從零行程積分，力在轉折點連續。第一段與末段延伸至表外。 |
| 彈簧力表 | 軸心壓縮行程 mm | 有號彈簧力 N | 至少兩點。點間線性插值，表外沿端點斜率延伸。 |
| 多段阻尼係數 | 各方向速度大小 m/s | 區段斜率 N·s/m | 壓縮和回彈各自從速度 0 開始。積分後的力在每個轉折點連續。 |
| 測功機力表 | 各方向速度大小 m/s | 力大小 N | 壓縮和回彈各至少兩點，由 `0,0` 起算。點間線性插值，表外保持末端力。 |
| 運動比 MR | 輪端或模態壓縮行程 mm | 局部軸心行程／輪端或模態行程 | 一列為常數。多列線性插值，表外保持端點比例。 |

在「彈簧與阻尼」選好通道後，可在力表旁按「匯入力表 CSV」。彈簧力表匯入後會切換成「彈簧力表」。阻尼若分成兩份檔案，先選「測功機力表」，再分別匯入壓縮和回彈。兩個方向共用同一組速度時，可按「匯入雙向 CSV」一次載入並切換成「測功機力表」。

| CSV 用途 | 欄位順序與選用欄名 | 數值列範例 |
| --- | --- | --- |
| 彈簧力表 | `travel_mm,force_n` | `10,400` |
| 單向阻尼力表 | `speed_mps,force_n` | `0.10,120` |
| 雙向阻尼力表 | `speed_mps,compression_n,rebound_n` | `0.10,120,175` |

使用 UTF-8、逗號分隔，每份可省略欄名。每張力表至少兩筆、最多 256 筆，行程或速度須遞增。阻尼的速度與力填大小，單向檔從 `0,0` 起算，雙向檔從 `0,0,0` 起算。匯入的數值隨專案 JSON 儲存。

主簧＋Tender 使用兩支彈簧的串聯剛性，Tender 併圈後切換到主簧。併圈欄位填 **Tender 自身**可壓縮的行程，軟段的總軸心行程會加上同一荷重下主簧的壓縮量。安裝預壓以彈簧曲線的行程偏移表示。壓縮與伸長限位各用正值輸入距離與剛性，剛性填 0 即停用該方向限位。除 Tender 外，通道的剛性曲線可承受雙向載荷。

各軸升沉取左右行程的和，側傾取左減右。前後同向側傾取兩軸側傾之和，對角扭擺取前軸減後軸。模態通道設定值對應這些座標。MR 沿輪端／模態行程積分得到軸心行程，瞬時軸心速度與回傳力再乘局部 MR。常數 MR 的線性元件因此得到 MR² 的輪端剛性與阻尼換算。[車輛安裝比推導](https://doi.org/10.3390/act11080229)

## ISO 路面與側向加速度

在「輸入工況」選擇 **ISO 8608 Class A、B 或 C**，設定車速（m/s）、路面隨機種子、輸入開始時間與作用輪位。預設四輪各自取樣，每輪使用同一等級的完整 PSD 頻帶與不同的隨機相位。同一等級和種子可重現各輪輪跡，同一輪位的輪跡也可在全車與局部模型之間重用。車速決定通過起伏的快慢。若車速較高，請依介面提示縮短輸出間隔。 [ISO 8608:2016](https://www.iso.org/standard/71202.html)

全車與 1/2 前後可勾選「同側後輪追蹤前輪」。左右兩側仍各自取樣，同側後輪會晚 `軸距 ÷ 車速` 秒通過前輪的輪跡。計算後可在曲線群組選擇「ISO 路面」與「全部」，疊圖比較各輪輸入。

全車與 1/2 左右可選 **側向加速度（轉彎）**，也可在 ISO 工況勾選 **疊加側向加速度 ay**。`ay` 以 m/s² 輸入，從「輸入開始」起，在設定的上升時間內平滑升至目標值並維持。正值使車身左側抬升，負值使右側抬升。可從「輸入」曲線查看實際 `ay` 和各輪路面高度，並在 CSV 取得同一份時間序列。

## 量測 CSV

欄名及順序如下。時間使用秒，路面高度使用 mm，車身工況加速度使用 m/s²。路面欄位填輪跡高程，垂直向上為正。`ax` 正值表示加速，`ay` 正值依本模型慣例令左側抬升。可先開啟隨附的 [CSV 範例](examples/road-replay.csv)。

```csv
time_s,z_fl_mm,z_fr_mm,z_rl_mm,z_rr_mm,ax_mps2,ay_mps2
0.00,0,0,0,0,0,0
0.25,5,0,0,0,-2,1
0.50,0,0,5,0,-3,2
```

回放時間以首筆歸零。路面採保形三次插值，首尾路面速度為零，加速度採線性插值。CSV 欄位格式共用，局部模型只讀取所選輪跡與支援的加速度。求解器以首筆有效輸入求模型各輪的接地平衡。若資料從尚在劇烈動態變化的區段開始，首筆平衡假設會影響起始暫態。CSV 會隨專案保存。

## 結果基準與模型範圍

每次先依重力、輪胎與已安裝元件求靜態平衡，再用自適應 Dormand–Prince 5(4) 積分。車身位移、側傾、俯仰與簧下位移以初始平衡為基準。輪端行程、元件軸心行程與車架扭角保留安裝基準，壓縮行程為正。輪荷是含靜態荷重的絕對值。零輪荷與限位警示依輸出取樣判定，短暫事件需要較密的輸出間隔。[Dormand–Prince 5(4) 說明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.RK45.html)

輪胎採垂直單向彈簧阻尼接觸，阻尼在接觸起點平滑接入，輪荷可降至零並在重新壓縮時恢復。全車仍使用小角度、固定側傾中心及 Anti 比例，加速度由工況指定。對實車的準確度取決於安裝基準、元件曲線、運動比、輪胎及車身參數是否經過實測校準。範例使用示意參數，尚未做實車對照驗證。
