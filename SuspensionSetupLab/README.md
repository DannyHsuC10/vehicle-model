# SuspensionSetupLab｜懸吊調校

在同一工況比較兩組車輛設定，觀察各輪輪荷、行程、姿態、限位與元件的力和速度。全車、半車與單輪模型共用 `new/dynamics_analyze` 的模態通道和可替換 KC 元件架構，介面與線性專案匯入延續 SuspensionDynamicsLab 的工作方式。

雙擊 **Start-SuspensionSetupLab.bat**，或在此資料夾執行 `python -m setup_lab`。需要 Python 3.10+、Tkinter 與 NumPy。實車 3D 使用 PyVista，請用啟動程式的同一個 Python 環境安裝下列依賴。載重轉移分配使用共用的 `new/Pacejka_tire_model`。若要單獨複製本工具，也可把 `Pacejka_tire_model` 放在 `SuspensionSetupLab` 內；計算只需該套件的 Python 模型、`tir_io.py` 與下方指定的 `.tir`，不需要預產生的查表檔。

```powershell
python -m pip install -r requirements.txt
python -m setup_lab --project examples/staged-setup.json
python -m setup_lab --project examples/staged-setup.json --csv staged-result.csv
python -m unittest discover -s tests -v
```

## 調校流程

1. 在「車輛與輪胎」填入總質量、重心、簧上慣量與每輪簧下質量、輪胎垂直剛性及阻尼。開啟「全車」、「1/2 左右」、「1/2 前後」或「1/4 車」頁籤，再選模型適用的輪位、車軸或側別。
2. 在「彈簧與阻尼」選擇通道，設定前後升沉、前後側傾、同向側傾、對角扭擺或 FL／FR／RL／RR 直推。在左側「此通道啟用於」分別勾選全車、1/2 左右、1/2 前後和 1/4 車。模型會套用所選軸或輪位對應的通道。彈簧、阻尼與 MR 參數在各模型間共用。下方顯示所選通道的元件曲線。舊專案的通道開關會帶入各適用模型。
3. 選擇目前模型適用的工況，或載入量測 CSV。各頁皆可選 ISO 8608 Class A、B、C。全車與 1/2 前後模型可對選中的後輪套用輪跡延遲。按 **F5** 計算。
4. 在「視覺化」播放、逐格或拖曳時間滑桿。全車頁左側顯示四輪法向輪荷、各輪懸吊通道合力、六組模態通道力、四輪直推力與車身姿態。懸吊通道合力由模態與直推通道投影到輪端後加總，停用通道顯示「—」。右側可切換「LP02 實車 3D」和「曲線」，兩者與監控面板共用同一條時間軸。拖曳實車畫面可旋轉，滾輪可縮放。1/2 左右使用前視動畫，1/2 前後與 1/4 車使用側視動畫，亦可切換至輪荷與姿態儀表板。拖曳分隔線可調整兩邊寬度。
5. 按「設目前結果為 A」，編輯參數或開啟另一份專案，再用相同模型、模型輪位、工況、車速及輸出間隔重算 B。曲線以虛線標示 A，指標頁顯示最低輪荷及車身升沉加速度 RMS 的差值。動畫與儀表板顯示目前結果。
6. 「匯出 CSV」輸出目前頁的結果。「儲存計算快照」另存該次計算的工況與參數。專案 JSON 可透過 Ctrl+O／Ctrl+S 開啟與儲存，包含四個分析頁的模型、工況及匯入的路面資料。開啟舊專案時，原本的「1/2 車」工況會放到對應的左右或前後頁。切換分析頁時，會暫停播放並保留各頁的結果與 A 基準。結果與 A 基準保留在本次開啟的程式中，可用 CSV 和計算快照留存。

可匯入 SuspensionDynamicsLab 的 `parameters.full` 專案及 VehicleInitialSizingLab 的 Dynamics JSON。線性係數會換算成介面的 N/mm 與 N·s/m，輪胎會換算到輪端，舊工況使用新工具預設值。來源若標記 Tender 但缺少併圈行程及安裝條件，會保留來源的線性剛性並顯示備註，供使用者在元件頁補齊。

LP02 視圖直接載入 `assets/LP02/` 內的車體與四輪 STL，保留 CAD 尺寸及輪位，以每次模擬的初始平衡狀態對應 CAD 靜態姿態。車身顯示升沉、俯仰和側傾，8 DOF 模式將前後側傾沿車身長度插值以呈現扭轉。四輪各自使用簧下垂向位移。轉向、外傾與車輪自轉需要額外的模型自由度。

路面虛線沿車輛中心線依工況車速往車尾移動，並與播放、暫停和時間滑桿同步。變更「車速 (m/s)」後按 F5，3D 視圖上方會顯示當次結果的車速（km/h）。

## 模型與通道

| 模型 | 自由度與輪位 | 使用的通道及工況 |
| --- | --- | --- |
| 1/4 車 | 2 DOF，簧上與簧下升沉。選 FL、FR、RL 或 RR。 | 該軸升沉、側傾與該輪直推。支援凸塊／凹坑及單輪路面回放。 |
| 1/2 左右 | 4 DOF，車身升沉、側傾及兩輪簧下升沉。選前軸或後軸。 | 該軸升沉、側傾與兩輪直推。支援路面、側向加速度與組合工況，含該軸側傾中心傳力。 |
| 1/2 前後 | 4 DOF，車身升沉、俯仰及前後輪簧下升沉。選左側或右側。 | 前後等效升沉及同側直推。支援路面、縱向加速度與組合工況，含前後 Anti 傳力與輪跡延遲。 |
| 全車 | 7 DOF 剛性車架或 8 DOF 可扭轉車架。8 DOF 將前後側傾分開。 | 全部通道及工況，含同向側傾、對角扭擺和四輪直推。 |

局部模型的簧上質量由全車重心的前後配重分配，各輪保留原本的簧下質量與輪胎參數。1/2 左右按該軸配重分配側傾慣量。1/2 前後採用全車簧上質量及俯仰慣量的一半，加上所選側前後兩輪的簧下質量。前後軸各用該輪相對車身的行程與 Heave MR 換算共用 Heave 元件的軸心行程，並將其反力的一半回傳給所選輪。固定 MR 時，Heave 對所選輪的剛性貢獻為該軸 Heave 剛性乘以 MR² 再除以 2。1/2 左右依兩輪各自的行程計算升沉與側傾。跨軸的同向側傾及對角扭擺由全車模型計算。[1/2 前後自由度與模型](https://doi.org/10.3390/2571-631X/7/4/55) · [1/2 左右與單軸互聯懸吊](https://journals.sagepub.com/doi/10.1177/09544070251395345)

## 元件曲線與單位

在「彈簧與阻尼」選擇「單一彈簧」即可用一個固定剛性 `k`（N/mm）設定該通道。彈簧力為剛性乘以軸心行程與安裝預壓行程之和。運動比、阻尼和行程限位仍可各自設定。

選好通道後，可在下拉選單設定彈簧和阻尼類型。選「查表彈簧剛性」或「查表阻尼」時，才會出現對應的 CSV 匯入按鈕。左圖顯示彈簧與限位合力（N）對軸心位移（mm）。超過限位起點後，合力從起點的彈簧力接續，斜率直接使用該側填入的總剛性。中間的阻尼圖顯示軸心速度與阻尼力，壓縮為正、回彈為負。

一段式阻尼的壓縮與回彈共用一個係數，兩段式各填一個。四段式的壓縮與回彈各填低速係數、高速係數和切換速度（m/s）。速度超過切換點後，阻尼力從低速段末端開始，按高速係數增加，兩段在切換點連續。首次選擇四段式時，兩側切換速度預設為 0.1 m/s，已存的分段曲線則沿用原有切換點。查表阻尼以一份 CSV 同時載入壓縮和回彈，各列填軸心速度和兩側阻尼力。

一段式、兩段式和四段式阻尼可勾選「使用阻尼比」，直接輸入無單位的比例 ζ（例如 0.7）。切換輸入方式時會換算現有值。阻尼係數以公式 $c = 2\zeta\sqrt{k m_\mathrm{ref}} / \mathrm{MR}$ 計算，$k$ 使用含安裝預壓的零行程彈簧切線剛性，MR 取零行程值，$m_\mathrm{ref}$ 使用固定輪端時各通道的簧上等效質量。阻尼圖顯示換算後的軸心速度與阻尼力。

運動比下拉選單提供「固定運動比」與「查表運動比」。固定模式在元件設定區填一個 MR 值。選用彈簧、阻尼或運動比的查表模式時，該元件會顯示 CSV 匯入按鈕並隱藏係數輸入欄。下方運動比圖顯示 MR 與輪端或模態懸吊行程（mm）的關係。

彈簧力圖以無空力靜態軸心位置為零點，預設將兩側限位相對於此位置的距離各延伸 10%。例如壓縮限位設為 10 mm，圖上壓縮側畫到 +11 mm。

| CSV 用途 | 欄位順序與選用欄名 | 數值列範例 |
| --- | --- | --- |
| 彈簧力表 | `travel_mm,force_n` | `10,400` |
| 阻尼力表 | `speed_mps,compression_n,rebound_n` | `0.10,120,175` |
| 運動比 | `travel_mm,mr` | `10,0.95` |

使用 UTF-8、逗號分隔，欄名可省略。每張力表至少兩筆、最多 256 筆，行程或速度須遞增。彈簧力使用有號值，表外沿端點斜率延伸。阻尼的速度與力填大小，從 `0,0,0` 起算，速度點之間線性插值，表外保持末端力。MR 一列為固定值，多列在行程點之間插值。匯入的曲線隨專案 JSON 儲存。

「Tender 靜態後併圈行程」與「靜態後壓縮限位起點」都從無空力靜態平衡位置起算。程式先求出含安裝預壓的無空力靜態位置，再加上各欄位指定的軸心壓縮量，固定門檻後計入下壓力。併圈前採用串聯剛性，併圈後採用主簧剛性，力在轉折點連續。開啟舊專案時，原有壓縮限位數值會用作靜態後的額外行程。伸長限位仍從安裝位置起算。限位剛性填 0 即停用該方向限位。

開啟舊專案時，原本的限位剛性增加量會加上限位外側緊鄰起點的彈簧剛性，換算成總剛性。若原彈簧在限位外還有轉折，換算後會以這個總剛性直線延伸。

全車與 1/2 左右的各軸 Heave 取兩輪行程的平均，Roll 取左減右後除以 2。Heave 反力均分至兩輪，Roll 反力則各以一半、相反方向作用於兩輪。固定 MR 時，兩輪同步升沉的整軸 Heave 剛性為 Heave 剛性乘以 MR²。全車的同向側傾與對角扭擺各有獨立通道，使用前後軸完整左右行程差的和與差。MR 沿輪端／模態行程積分得到軸心行程，瞬時軸心速度與回傳力再乘局部 MR。[車輛安裝比推導](https://doi.org/10.3390/act11080229)

1/4 車的 Heave 和 Roll 各使用「彈簧與阻尼」頁上該通道的運動比。每個通道以一半輪端行程換算軸心行程，支援固定 MR 與查表 MR。使用固定 MR 時，輪端剛性為 $K_{\mathrm{heave}}(MR_{\mathrm{heave}}/2)^2 + K_{\mathrm{roll}}(MR_{\mathrm{roll}}/2)^2$。使用 Tender 時，Heave 在併圈前採串聯剛性，併圈後採主簧剛性。舊專案的單輪 MR 欄位會略過。

## 空力下壓力

在「空力」頁填寫參考車速（km/h）及對應的全車下壓力（N，向下為正），勾選「啟用空力」。曲線會即時標出參考點和最近使用的分析頁工況車速。新專案及舊版 JSON 預設停用空力，參考點的 100 km/h、500 N 是示例值。

假設升力係數、空氣密度和參考面積固定，由參考點求得 `F(v) = F_ref × (v / v_ref)²`。各分析頁的「車速 (m/s)」會換算為 km/h，再代入曲線。此車速在整段模擬中固定，量測 CSV 回放也使用工況欄位的車速。

下壓力由初始平衡起施加於簧上重心。半車與單輪模型按重心位置分配前後軸比例，再在同軸左右均分。計算後可在「空力」曲線和 CSV 查看全車下壓力及局部模型承受的份額。用相同車速跑兩次可比較開關空力對輪荷和行程的影響。 [NASA 升力方程式](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/lift-equation/)

## 準靜態載重轉移

「載重轉移分配」沿用簧下、幾何、彈性三路徑法。前後彈性分配取自本專案懸吊通道在無空力靜態位置的側傾切線剛性，前軸 LLTD 採前軸轉移量占前後轉移量的比例。啟用空力時，依彎道半徑與側向加速度換算車速後疊加下壓力。

按「匯入 .tir」可切換前後軸共用的輪胎參數。支援 SI 單位的 MF6.1 `.tir`（`FITTYP=61`）。匯入成功會重新計算，儲存專案時會把 `.tir` 內容一併寫入 JSON，日後開啟專案會載入當時匯入的版本。「恢復預設」會切回 `tir/Hoosier_43075_R20_W8_candidate.tir`。

側向力、抓地與滑角直接使用 `Pacejka_tire_model` 的 MF6.1.2 `FY0`。這是穩態純轉彎分析，縱向滑移及外傾皆為零。模型以各輪輪荷及所屬軸胎壓計算側向力，抬輪時側向力為零。每軸用同一滑角滿足總側向力需求，抓地百分比是該方向的軸峰值側向力，相對於同車速、含空力但左右未轉移載重時的峰值。需求超出上限時，無解車軸的滑角、側向力及整車轉向顯示空值。輪荷和胎壓超出 `.tir` 適用範圍時，模型會外插。

工況、胎壓及接地面胎寬隨專案儲存；舊專案仍可開啟，舊有的摩擦係數、載重敏感度、參考荷重與 B/C/E 不再用於計算。垂直輪胎剛性和阻尼仍在「車輛與輪胎」設定。

圖表包含四輪輪荷、側傾角、前後軸轉移量、簧下／幾何／彈性力矩、穩態轉向、不足轉向梯度與剩餘抓地曲線。「接地面」分頁用分配後的輪荷、前後胎壓和胎寬估算四輪接地橢圓。修改胎壓或胎寬後按「更新計算」套用。滑桿可即時預覽 −3 至 +3 g 的前後軸轉移量、四輪輪荷及接地尺寸，預覽時保持圖的比例尺。輪荷小於或等於零時，接地面積為零並標示抬輪。

## 1/2 左右暫態載重轉移

在 1/2 左右模型完成計算後，可在「視覺化」選擇「載重轉移量」或「載重轉移速率」，同圖比較 Roll Center 幾何傳力、懸吊反力（含彈簧、阻尼與限位）、兩條路徑的合計，以及輪胎接地端的法向輪荷。各曲線採左右力差的一半，扣除起始值。正值表示相對起始狀態偏向右輪，負值表示偏向左輪。輪胎端與路徑合計的差會隨簧下慣性反應變化。

速率以實際輸出時間對轉移量作數值微分，保留正負值。兩組曲線圖都會標示各曲線絕對值最大的點，並在圖上方列出帶正負號的峰值及時間。「調校指標與警示」也會列出速率峰值，匯出 CSV 會包含兩組訊號。幾何力使用當下的側向加速度；選擇 CSV 查表時，Roll Center 高度按當下行程取得。

「Roll Center 掃描」以目前所選車軸和工況計算基準高度 ±10 mm 的 21 個點。每點取全時段輪胎端載重轉移速率的最大絕對值，圖中標出評分最低的高度與基準差值。CSV 模式以零行程高度為基準，等量平移該軸的高度曲線。「查看最佳工況曲線」可開啟該點的模擬結果，專案設定仍以原本輸入為準。

「車輛與輪胎」頁可調整 1/2 左右模型的 Roll Center 車架傳力，包含等效剛性（N/m）、阻尼（N·s/m）及慣性質量（kg）。預設開啟，設定隨專案儲存。開啟後，幾何力的指令驅動虛擬質量，彈簧與阻尼反力再施加到左右簧下，幾何載重轉移曲線採實際傳遞力。車身仍即時收到 Roll Center 的改變力矩。可在「視覺化」的「車架傳力」曲線同時查看指令與傳遞力。取消勾選時改用即時傳力。

## 幾何查表

「幾何查表」頁提供 Roll Center 和 Anti 各自的下拉選單，可切換「固定值」或「CSV 查表」，下方並排顯示兩組曲線。選擇固定值可在同頁輸入前後 Roll Center 高度（m）和四個 Anti 比例（例如 0.15 代表 15%）。選擇 CSV 查表可匯入 CSV 或匯出範本。每列的 `travel_mm` 是該軸平均輪端行程相對無空力、無加速度靜態平衡位置的變化量，壓縮為正。前後軸各自用自己的行程讀取同一張表。表內採線性內插，超出範圍使用最近端點值。

- Roll Center 欄名為 `travel_mm,front_rc_mm,rear_rc_mm`，高度單位 mm。
- Anti 欄名為 `travel_mm,front_anti_dive_pct,rear_anti_lift_pct,front_anti_lift_pct,rear_anti_squat_pct`，比例以百分數輸入，例如 15 代表 15%。

模式、固定值和匯入的表格會隨專案儲存，切換模式時可沿用先前的設定。動態模擬在每個求解步讀取當下的幾何值，曲線和匯出 CSV 可查看各通道的查表結果。「載重轉移分配」是準靜態模型，使用 CSV 查表時，Roll Center 採表內的零行程值。

## ISO 路面與側向加速度

在「輸入工況」選擇 **ISO 8608 Class A、B 或 C**，設定車速（m/s）、路面隨機種子、輸入開始時間與作用輪位。預設四輪各自取樣，每輪使用同一等級的完整 PSD 頻帶與不同的隨機相位。同一等級和種子可重現各輪輪跡，同一輪位的輪跡也可在全車與局部模型之間重用。車速決定通過起伏的快慢。若車速較高，請依介面提示縮短輸出間隔。 [ISO 8608:2016](https://www.iso.org/standard/71202.html)

全車與 1/2 前後可勾選「同側後輪追蹤前輪」。左右兩側仍各自取樣，同側後輪會晚 `軸距 ÷ 車速` 秒通過前輪的輪跡。計算後可在曲線群組選擇「ISO 路面」與「全部」，疊圖比較各輪輸入。

全車與 1/2 左右可選 **側向加速度（轉彎）**，也可在 ISO 工況勾選 **疊加側向加速度 ay**。`ay` 以 m/s² 輸入，從「輸入開始」起，在設定的上升時間內平滑升至目標值並維持。正值使車身左側抬升，負值使右側抬升。可從「輸入」曲線查看實際 `ay` 和各輪路面高度，並在 CSV 取得同一份時間序列。

## 量測 CSV

回放依欄名讀取下列訊號，亦接受圈速結果的 `ax_m_s2` 和 `ay_m_s2`。可使用任意欄位順序並保留其他欄位。缺少路面或加速度欄位時，程式會列出缺少的欄位，經確認後以 0 補齊。時間 `time_s` 為必填欄位。

時間使用秒，路面高度使用 mm，車身工況加速度使用 m/s²。路面欄位填輪跡高程，垂直向上為正。`ax` 正值表示加速，`ay` 正值依本模型慣例令左側抬升。可先開啟隨附的 [CSV 範例](examples/road-replay.csv)。

```csv
time_s,z_fl_mm,z_fr_mm,z_rl_mm,z_rr_mm,ax_mps2,ay_mps2
0.00,0,0,0,0,0,0
0.25,5,0,0,0,-2,1
0.50,0,0,5,0,-3,2
```

回放時間以首筆歸零。路面採保形三次插值，首尾路面速度為零，加速度採線性插值。CSV 欄位格式共用，局部模型只讀取所選輪跡與支援的加速度。求解器以首筆有效輸入求模型各輪的接地平衡。若資料從尚在劇烈動態變化的區段開始，首筆平衡假設會影響起始暫態。CSV 會隨專案保存。

## 結果基準與模型範圍

長資料可在分析頁按「純計算並匯出 CSV」，選擇輸出路徑後於背景逐筆寫檔。此模式沿用相同的動態求解器，跳過動畫與曲線資料的建立，並可超過一般動畫模式的 30,001 筆。輸出包含模型支援的俯仰、側傾與升沉，以及各所選輪位的輪心與簧上角點垂直位移、速度、加速度、懸吊行程、輪荷與元件反力。全車模型輸出四輪，垂直位移以起始平衡為零。停止或求解失敗時不會覆寫指定的 CSV。

每次先依重力、啟用的空力、輪胎與已安裝元件求靜態平衡，再用自適應 Dormand–Prince 5(4) 積分。車身位移、側傾、俯仰與簧下位移以初始平衡為基準。輪端行程、元件軸心行程與車架扭角保留安裝基準，壓縮行程為正。輪荷是含靜態荷重的絕對值。零輪荷與限位警示依輸出取樣判定，短暫事件需要較密的輸出間隔。[Dormand–Prince 5(4) 說明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.RK45.html)

1/2 前後的「輪端行程」圖會依前後 Heave 各自的 MR，標示已啟用的壓縮、伸長限位，以及 Tender 併圈門檻。＋代表併圈，× 代表回到串聯段。選擇單一輪端曲線時，只顯示該軸對應的門檻與切換點。

「輸出間隔」決定曲線、動畫及 CSV 的結果取樣時間。積分器的步長依誤差調整，並在下一個輸出點或路面事件前截短。一般內部步長上限為 5 ms，凸塊與 ISO 路面可能要求更短。縮短輸出間隔會增加取樣密度，也可能增加積分步數。

輪胎採垂直單向彈簧阻尼接觸，阻尼在接觸起點平滑接入，輪荷可降至零並在重新壓縮時恢復。全車使用小角度模型，加速度由工況指定。側傾中心及 Anti 可使用固定值或一維行程查表。對實車的準確度取決於安裝基準、元件曲線、運動比、輪胎及車身參數是否經過實測校準。範例使用示意參數，尚未做實車對照驗證。
